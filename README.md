# SimpleShader —— 从零开始 Minecraft 光影开发

一个**面向学习**的 Minecraft 光影（shader pack）。目标不是"最好看"，而是
**每一行代码都能看懂、每一个效果都知道为什么这么做、想加新效果时知道从哪里下手**。

```
Shader/
├── README.md              你正在读的文件
├── tools/
│   ├── check_glsl.py      不启动游戏就能跑的编译检查（32 个程序全通过）
│   └── deploy.sh          把光影同步到游戏目录（处理版本隔离）
├── docs/                  教程文档（建议按编号顺序读）
│   ├── 01-GLSL基础.md
│   ├── 02-着色器管线与程序类型.md
│   ├── 03-坐标系与空间变换.md
│   ├── 04-光照模型.md
│   ├── 05-阴影映射.md
│   ├── 06-后处理与色调映射.md
│   ├── 07-调试排错与性能.md
│   ├── 08-扩展指南.md
│   └── 09-参考速查表.md
└── shaders/               光影本体（这个目录就是"光影包"）
    ├── shaders.properties 光影设置界面配置
    ├── settings.glsl      所有可调参数集中在这里
    ├── lang/              界面文本（中/英）
    ├── lib/               公共库：所有程序共用的函数
    ├── shadow.vsh/.fsh    阴影贴图通道
    ├── gbuffers_*.vsh/.fsh 几何通道（把场景画进 G-Buffer）
    ├── composite*.vsh/.fsh 后处理通道（泛光）
    └── final.vsh/.fsh     最后一步（色调映射 + 输出到屏幕）
```

## 一、装它

### 前置条件

光影不是模组，它需要**支持光影的加载器**：

| 游戏版本 | 推荐方案 |
|---------|---------|
| 1.20.x 及更早 | OptiFine（自带光影支持） |
| 1.21.x（含 1.21.11） | **Iris + Sodium**（OptiFine 对新版本跟进很慢，1.21 上建议直接用 Iris） |

本光影只使用最基础、最通用的特性（GLSL 120、标准 OptiFine uniform），
OptiFine 和 Iris 都能正常加载。

### 安装步骤

**本机已经装好了**，而且已经拷贝到游戏真正读取的目录：

```
~/.minecraft/versions/1.21.11-Forge-OptiFine/shaderpacks/SimpleShader/shaders/
```

⚠️ 注意这个游戏实例开了**版本隔离**，所以光影要放在
`versions/<版本名>/shaderpacks/` 里，而不是 `~/.minecraft/shaderpacks/`
—— 放错位置的话，游戏的光影列表里根本看不到它。

改完代码后用一条命令同步过去：

```bash
bash tools/deploy.sh
```

然后在游戏里按 **`F3 + R`** 重载（比重启游戏快得多）。

游戏内选中方式：`选项 -> 视频设置 -> 光影 -> SimpleShader`。

给别的机器/别人的安装方式：

1. 把 `shaders` 整个目录压缩成 zip（**注意**：zip 里必须直接是 `shaders/`，
   不能是 `Shader/shaders/`，否则游戏识别不到）。
2. 放进 `.minecraft/shaderpacks/` 目录。
3. 游戏内选中它。
4. 想改参数：`光影设置` 界面，或者直接改 `shaders/settings.glsl`。

> 开发时**不要**每次打包 zip。Iris/OptiFine 支持把 `shaders`
> 目录直接放进 `shaderpacks/`（作为文件夹或软链接），改完按 `F3 + R` 重载即可。
> 修改 `settings.glsl` 里的参数则不需要重载。

## 二、这个光影做了什么

### 渲染管线（一帧的流程）

```
  ┌─ shadow ──────────────────────────────────────────┐
  │ 站在太阳的位置渲染一遍场景，只记深度 -> 阴影贴图   │
  └───────────────────────────────────────────────────┘
                          ↓
  ┌─ gbuffers_* ──────────────────────────────────────┐
  │ 从玩家视角渲染场景，每个像素同时输出三张图：       │
  │   colortex0 = 颜色（HDR）                          │
  │   colortex1 = 法线 + 材质标记                      │
  │   colortex2 = 光照信息 + 阴影系数                  │
  └───────────────────────────────────────────────────┘
                          ↓
  ┌─ composite ───────────────────────────────────────┐
  │ 提取画面里过亮的像素（亮部提取）                   │
  └───────────────────────────────────────────────────┘
                          ↓
  ┌─ composite1 ──────────────────────────────────────┐
  │ 把这些亮部模糊成大范围的光晕（泛光）               │
  └───────────────────────────────────────────────────┘
                          ↓
  ┌─ final ───────────────────────────────────────────┐
  │ 颜色 + 泛光 -> 色调映射 -> 暗角 -> gamma -> 屏幕   │
  └───────────────────────────────────────────────────┘
```

### 已经实现的效果

- **方向光照**：Lambert 漫反射，光的颜色随日出日落变化
- **阴影**：2048² 阴影贴图 + 畸变 + 3x3 PCF 软阴影 + 距离淡出
- **环境光**：直接复用 Minecraft 的光照贴图，火把暖光/天空冷光免费获得
- **雾**：按渲染距离自定义的大气雾，含独立的水下雾
- **水面**：顶点波浪 + 逐像素法线 + 高光
- **后处理**：HDR、泛光、ACES 色调映射、曝光/饱和度/对比度、暗角、抖动
- **调试视图**：7 种中间结果可视化（开发时最有用）
- **设置界面**：20+ 个可调选项，中英文界面

### 故意**没有**做的东西

理解"为什么不做"和"怎么做"同样重要：

- 没有屏幕空间反射（SSR）、环境光遮蔽（SSAO）—— 这些是进阶内容，
  `docs/08-扩展指南.md` 给出了完整的实现步骤和需要的工具函数（已备好）。
- 没有延迟渲染（deferred）—— 本项目在 gbuffer 阶段直接算光照，
  更适合入门。想改成延迟管线，扩展指南里说明了怎么迁移。
- 没有体积光、PBR 材质、天气特效 —— 都是很好的练手题目。

## 三、怎么读这份代码

### 推荐顺序

1. **先读代码**：`shaders/gbuffers_terrain.vsh` -> `.fsh`。
   这是全项目的核心，其余 15 个程序都是它的简化版或特化版。

2. **再读库**：按 `lib/` 里被引用的顺序
   - `uniforms.glsl` 所有输入数据是什么
   - `common.glsl` 数学工具
   - `space.glsl` 坐标怎么变换
   - `lighting.glsl` 颜色怎么算出来的
   - `shadow.glsl` 阴影怎么采样的
   - `fog.glsl` / `tonemap.glsl` / `noise.glsl` / `debug.glsl`

3. **然后读文档**：`docs/01` → `docs/09`。
   文档不是代码的复述，而是补上代码没法表达的部分：
   为什么这样算、有什么替代方案、坑在哪里。

4. **最后动手改**：从 `docs/08-扩展指南.md` 里挑一个最简单的
   （"让草方块顶面更亮"五行代码），改完进游戏看效果。
   改光影最爽的地方就是反馈极快：`F3 + R` 一秒重载。

### 读代码的约定

| 前缀 | 含义 |
|-----|------|
| `va*` | 顶点属性（Vertex Attribute），OptiFine 送进来的原始数据 |
| `v*` | varying，顶点着色器传给片元着色器并插值的数据 |
| `mc_*` | OptiFine 的特殊属性（方块 ID 等） |
| `MAT_*` | 材质标记，写在 G-Buffer 里给后处理用 |
| 全大写 | 宏与设置项，都可以在 `settings.glsl` 或游戏内调整 |

## 四、动手前的两个心态提醒

1. **光影是"数据流"而不是"画图"**。
   不要想"我要在这里画一条阴影"，而要想
   "这个像素在哪些光源下、被谁遮挡、它表面朝哪、它是什么材质"。
   把数据算对，画面自然就对。

2. **先让它跑起来，再让它好看**。
   改完立刻进游戏看，看到不对就打开调试视图
   （`settings.glsl` 里把 `DEBUG_VIEW` 改成 1~6），
   直接看是法线错了、阴影错了还是光照贴图没取对。
   靠猜是猜不出来的。

## 五、遇到问题

先看 `docs/07-调试排错与性能.md` 的"症状 -> 原因"对照表，覆盖了新手
90% 的问题：画面全黑、全白、偏灰、阴影错位、水面闪烁、帧率暴跌等。

如果光影完全无法加载，先确认：

- 用的是 Iris/OptiFine，而不是原版
- zip 结构正确（顶层就是 `shaders/`）
- 游戏日志里搜 `shader` 看编译错误（编译错误会直接告诉你行号）
