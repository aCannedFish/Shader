# 纹理来源

`sky-noise.png` 上部为本项目确定性生成的周期性云密度噪声，生成程序为 `tools/build_sky_assets.py`。

下部月面颜色来自 NASA's Scientific Visualization Studio，CGI Moon Kit 提供的 LRO/LROC 月球颜色图。原作者 Ernie Wright，数据来自 Lunar Reconnaissance Orbiter。项目将 2048×1024 数据缩小至 512×256 后打包，不添加原图没有的月面内容。

- [月面数据](https://svs.gsfc.nasa.gov/4720/)
- [原始颜色图](https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg)
- [NASA SVS 使用说明](https://svs.gsfc.nasa.gov/help/)：无另行标注的内容属于公共领域，允许使用和再分发。
