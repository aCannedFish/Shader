# 雨天

## 过渡

天空逐渐转为较暗的中性灰，日月直射与云层环境光随雨量减弱。地表与水面倒影读取同一套天空、云环境；配套 Mod 同步减弱日月 GI 入射能量。局部光源保持独立照明。

雨丝采用深蓝灰色，远处随雾消隐。默认资源包中的蓝色落地水花及低红色青色变体使用相同配色与中性环境照明；颜色识别在贴图与顶点染色相乘后进行。中性色、暖色及明亮青色粒子保留原色。这一水花识别依据原版贴图色差，相似颜色的自定义粒子资源包需另行核对。

天气保留原始顶点透明度，空贴图片元显式丢弃。雨幕混合后以现有颜色缓冲的 alpha 保存背景透射率；最终雾色修正只执行一次，并按背景透射率加权，避免给远处雨丝重复染色。天空已在不透明阶段填充，雨丝覆盖处保留其混合结果。

水面合成读取不透明场景副本，会重建并替换此前的场景颜色。为保留覆盖水面的雨丝，天气阶段向 `colortex1` 的 B/A 通道加法累积亮度矩与光学深度，R/G 水面参数保持不变。合成时扣除水面的基准有效值，恢复雨层透射和蓝灰辐射；水下观察水上场景也读取该层。同亮度雨层等价于连续 alpha 混合；跨越不同照明的多层雨丝采用光学深度加权亮度近似，不保存逐层排序。

粒子通过 `particles.before.deferred=true` 在不透明后处理前绘制，避免水花的法线、光照输出覆盖水面元数据。该选项来自 [OptiFine 渲染属性](https://github.com/sp614x/optifine/blob/master/OptiFineDoc/doc/shaders.properties)。水花按自身深度进入不透明副本，再参与后续水面遮挡。

## 积水

积水是地表薄水层近似，以连续噪声描述局部聚集，随加载器湿度积累并在雨后退去。它不修改世界方块，也不模拟真实坑洼容积。原生天光、顶面朝向及配套地表高度限制积水范围，树叶、墙面和屋檐下的地板保持各自材质。

水层减弱地表漫反射，并叠加受 Fresnel 和粗糙度控制的单次倒影。SSR 复用材质反射预算与已存在的颜色 mip；关闭材质反射时保留地表湿润变暗。群系降水类型经平滑后用于排除雪地与干燥群系，边界处属于相机所在群系的近似。

## 雾气

森林与山坡的雨雾沿配套 Mod 记录的真实地表分布。雨量主要增加近地密度，默认高度衰减尺度为四个方块，离地十二个方块时退出；大尺度、低对比度的静态分布保留厚薄差异。密度不再循环平移，避免平面噪声形成摆动的竖向雾墙。阴雨时以天空漫射光照亮雾层，强降雨下关闭方向光束，局部介质的不透明度限制为 40%。地面雾与雨雾可分别控制；两者复用现有体积视口和积分预算，遇到近处几何时按深度截断。

“世界 → 雨天”提供地表积水和山林雨雾强度。雨雾依赖配套 Mod 的地表缓存；无有效缓存时不生成局部山林雾，天空与普通远景雾仍可响应降雨。

## 开销

晴天地表跳过湿润几何重建和积水反射。水面倒影新增颜色副本的 mip 构建，命中过滤由稀疏九点改为四点连续足迹；反射步数与体积积分步数沿用原配置。积水会为被覆盖的地表增加一次反射查询，因此雨天开销与地面覆盖面积有关，不能由采样点数直接推算整机帧率。

雨层复用既有附件，保持 macOS 支持的八个颜色附件上限，见 [OptiFine 缓冲说明](https://github.com/sp614x/optifine/blob/master/OptiFineDoc/doc/shaders.txt)。`colortex1` 从 RGBA8 改为 RGBA16F，1080p 双缓冲增加约 16 MiB 显存；天气绘制增加一次附件写入，水面合成增加雨层读取与透射解码，未增加反射或体积积分步数。

SSR 仍无法重建离屏或被遮挡后的完整场景，反射边界的稳定性也受不透明深度精度约束。水体与积水的高光过滤参考 [Filament 的高光抗锯齿说明](https://google.github.io/filament/Materials.md.html)；雨天薄水层的设计参照 [Tatarchuk 的实时雨景渲染讲义](https://advances.realtimerendering.com/s2006/Tatarchuk-Rain.pdf)，采用本项目自己的噪声、几何约束和预算。

## 水色

水面散射色直接在线性空间定义，保留少量群系色相差异，并由实际环境光与直射光决定亮度。不透明水层用受光水色补足被遮蔽的水底辐射，减轻深水偏蓝黑的问题。环境倒影使用 0.14 的美术反射基值及较弱的粗糙度去相干，提高场景颜色占比，继续用粗糙 mip 过滤控制轮廓。该基值服务于观感调节，并非纯水的物理 F0。散射不透明度、吸收距离和水下相机的可见距离不变。

## 验证

2026-10-22 使用正式存档的独立副本完成晴天水面、雨幕重叠、水花、玻璃前方水面、水下玻璃、远处水面、浅水台阶及日照高光八个原生镜头。旧版雨丝在水面处消失，修改后可连续覆盖水面；水花镜头下半幅的亮青像素由 244 个降为 0，该统计只说明此固定镜头的色偏消除，不代表任意资源包。GLSL 探针另验证同亮度多雨层与连续 alpha 混合一致，干燥水面参数保持原值。
