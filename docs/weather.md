# 雨天

## 过渡

天空逐渐转为较暗的中性灰，日月直射与云层环境光随雨量减弱。地表与水面倒影读取同一套天空、云环境；配套 Mod 同步减弱日月 GI 入射能量。局部光源保持独立照明。

雨丝采用深蓝灰色，远处随雾消隐。默认资源包中的蓝色落地水花同步压暗，雪花及青色灵魂火粒子保留原色。这一水花识别依据原版贴图色差，自定义粒子资源包需另行核对。

天气保留原始顶点透明度，空贴图片元显式丢弃。雨幕混合后以现有颜色缓冲的 alpha 保存背景透射率；最终雾色修正只执行一次，并按背景透射率加权，避免给远处雨丝重复染色。天空已在不透明阶段填充，雨丝覆盖处保留其混合结果。

## 积水

积水是地表薄水层近似，以连续噪声描述局部聚集，随加载器湿度积累并在雨后退去。它不修改世界方块，也不模拟真实坑洼容积。原生天光、顶面朝向及配套地表高度限制积水范围，树叶、墙面和屋檐下的地板保持各自材质。

水层减弱地表漫反射，并叠加受 Fresnel 和粗糙度控制的单次倒影。SSR 复用材质反射预算与已存在的颜色 mip；关闭材质反射时保留地表湿润变暗。群系降水类型经平滑后用于排除雪地与干燥群系，边界处属于相机所在群系的近似。

## 雾气

森林与山坡的雨雾沿配套 Mod 记录的真实地表分布。雨量主要增加近地密度，默认高度衰减尺度为四个方块，离地十二个方块时退出；大尺度、低对比度的静态分布保留厚薄差异。密度不再循环平移，避免平面噪声形成摆动的竖向雾墙。阴雨时以天空漫射光照亮雾层，强降雨下关闭方向光束，局部介质的不透明度限制为 40%。地面雾与雨雾可分别控制；两者复用现有体积视口和积分预算，遇到近处几何时按深度截断。

“世界 → 雨天”提供地表积水和山林雨雾强度。雨雾依赖配套 Mod 的地表缓存；无有效缓存时不生成局部山林雾，天空与普通远景雾仍可响应降雨。

## 开销

晴天地表跳过湿润几何重建和积水反射。水面倒影新增颜色副本的 mip 构建，命中过滤由稀疏九点改为四点连续足迹；反射步数与体积积分步数沿用原配置。积水会为被覆盖的地表增加一次反射查询，因此雨天开销与地面覆盖面积有关，不能由采样点数直接推算整机帧率。

SSR 仍无法重建离屏或被遮挡后的完整场景，反射边界的稳定性也受不透明深度精度约束。水体与积水的高光过滤参考 [Filament 的高光抗锯齿说明](https://google.github.io/filament/Materials.md.html)；雨天薄水层的设计参照 [Tatarchuk 的实时雨景渲染讲义](https://advances.realtimerendering.com/s2006/Tatarchuk-Rain.pdf)，采用本项目自己的噪声、几何约束和预算。

## 水色

水面散射色直接在线性空间定义，保留少量群系色相差异，并由实际环境光与直射光决定亮度。不透明水层用受光水色补足被遮蔽的水底辐射，减轻深水偏蓝黑的问题。散射不透明度、吸收距离和水下相机的可见距离不变；倒影继续使用场景自身的颜色。
