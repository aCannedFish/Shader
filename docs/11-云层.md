# 云层

云由程序生成的立体方块组成，不使用云贴图。默认位于世界高度 192～208，厚度 16 方块；可以从下方、上方或内部观察，也可以自由穿过。白色半透明材质接受天空、太阳和月亮的色调与明暗变化。

## 云形

生成分为布局、骨架和体素化三步。

布局把世界划分为默认 320 方块宽的区域。每个区域用固定坐标哈希决定是否存在云团、中心偏移、旋转方向和形状类型。边缘保留空格，使云团不会意外连接成覆盖整个天空的一层；雨天适度提高覆盖率。

骨架支持团簇、狭长、弯折和分叉四类形态。每团包含六段主干，各段长度、转向和宽度分别变化；团簇与分叉类型还生成侧枝。弯折类型保留凹口，其他类型有不同的长宽比例。随机参数由世界区域决定，不随帧重新抽取。

体素化把骨架段周围的空间转成 12×12 方块宽的占用格子。小幅外围扰动增加一格尺度的缺口和折线，内部骨架保持连接。每个占用格子从云层底部一直延伸到顶部，因此保留水平顶面、底面和竖直侧面。

## 绘制

`lib/clouds.glsl` 在云层范围内沿 X/Z 格子边界行进，精确寻找云团外表面。相邻占用格子之间不绘制内部面；相机进入云内时，继续寻找出口面，避免把透明面贴在眼前。

云在 `composite.fsh` 中与已经绘制的场景合成。`depthtex0` 提供场景的最近深度，云求交距离被该深度裁剪，因此前方地形挡住云；从云层上方俯视时，云可以遮住后方地形。颜色使用预乘 alpha 按从近到远的顺序累积，合成后再计算泛光和色调映射。

这种绘制方式参考格子遍历方法 [Amanatides 与 Woo，1987](https://www.cse.yorku.ca/~amana/research/grid.pdf)。深度缓冲的含义见 [Iris DepthTex 文档](https://shaders.properties/current/reference/buffers/depthtex/)。云形占用和材质计算不采样贴图；场景颜色与深度仍使用渲染管线的缓冲区。

## 移动

整个格子场按风速刚性平移，云团形状保持不变，侧面连续移动。默认速度为每秒约 0.6 方块，另带少量 Z 方向分量。速度设为 0 时云停止移动。

## 参数

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `CLOUD_HEIGHT` | 192.0 | 云层底部高度 |
| `CLOUD_THICKNESS` | 16.0 | 厚度，为最初 4 方块实现的四倍 |
| `CLOUD_CELL_SIZE` | 12.0 | 水平云块宽度 |
| `CLOUD_SIZE` | 216.0 | 云团骨架的尺寸基准 |
| `CLOUD_SPACING` | 320.0 | 云团布局区域的间距 |
| `CLOUD_SPEED` | 0.6 | 水平平移速度 |
| `CLOUD_OPACITY` | 0.65 | 单个外表面的不透明度，0 关闭云 |

以上参数已加入“世界”设置，并提供中英文名称。多个云团沿同一视线叠加时，累计不透明度会提高。云的布局不是原版云贴图的逐点复制，采用相同的方块轮廓风格和厚度边界。

## 验证

固定场景包含云层下方、内部、上方和同一镜头的延时采样，场景名分别为 `cloud_below`、`cloud_inside`、`cloud_above`、`cloud_motion`。`python3 tools/preview.py verify` 比较实际 GPU 输出与游戏采集基准，并检查半透明和失败路径。

移动验证可使用仅输出云 alpha 的诊断程序，排除天空亮度与抖动的影响；速度为 0 的两帧应一致，非零速度的两帧轮廓应变化。默认结果保存在 `.preview/latest/`。
