# 水下

## 合成

水下由 `composite2.fsh` 与 `lib/underwater.glsl` 合成。先保留不透明场景和粒子；透明阶段混入的薄层水色由不透明副本替换，再按水内光程应用一次吸收与散射。

从水下看水上时，水面界定水内路径的终点。按水面前后的深度差区分水下前景与水上景物；只有穿过界面的部分接受九点粗糙透射过滤和水面下侧的环境反射。斜视时反射占比增强，接近垂直上望时透射占比提高，跨水面的物体因而具有可辨识的明暗与清晰度分界。

水下反射采用宽瓣近似，颜色来自当地水体散射与水面局部光照，随昼夜、天光和方块光变化。它不重建单个水内物体的镜像。可见的水上景物仍保留一定透射，角度过渡连续，没有硬切的临界角圆形窗口。此处独立于水上的反射强度设置。

波浪相位锚定水面交点，采样偏移最多 1.25 像素，并在到达轮廓前平滑减弱。界面合成完成后，只对相机到水面的水内路径施加吸收。位于水面前方的水下物体保持原始采样，不接受界面反射与过滤。

## 可见度

浸入深度每帧通过九个固定水面探针估计一次，只接受近似水平的水面并平均有效高度，减少侧壁误判和最低波峰切换；视野不含水面时，以原版天光等级近似。元数据最初写入云附件的首个红色纹素，水下散射通道再转存至首个 alpha 纹素。天空散射随深度和当地天光减弱，方块光保持独立。

附近物体保留有限的透射下限，9～18 方块间逐渐退出，远景继续按光程衰减。移除全反射窗口后，仍然保留水内吸收，深水不会变成完全透明的空气。

## 聚光

柔和聚光通过两层低频平滑噪声模拟水下光线的明暗起伏。沿太阳在水中的方向投影到水面，受阴影、水深和接收面朝向调制；在已有亮度上小幅增减，维持温和的平均能量。它不绘制窄亮边，也不模拟光子会聚。

水下日照光柱在半分辨率执行八步散射积分，在体积点查询现有不透明阴影，并在实际阴影纹素中心比较后双线性插值。宽核组合四组比较，防止按变化半径重新划分采样网格造成跳变。固定中点采样减少随机颗粒。折射后的太阳方向随日照角度改变。场景合成根据每个散射纹素的路径深度做四点重建，减少跨越近处物体的漏光。夜晚和封闭洞穴关闭日照光柱。

## 参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `UNDERWATER_MIN_VISIBILITY` | 0.12 | 附近物体的最低透射与散射基底 |
| `UNDERWATER_DENSITY` | 1.0 | 水下光程衰减倍率 |
| `UNDERWATER_DEPTH_DIMMING` | 1.0 | 深度对天空散射和光柱的衰减 |
| `WATER_REFRACTION_STRENGTH` | 1.0 | 水下界面轻微波动，0 关闭偏移 |
| `WATER_CAUSTICS_STRENGTH` | 0.65 | 柔和聚光与明暗起伏，0 关闭 |
| `UNDERWATER_SHAFT_STRENGTH` | 0.7 | 水下日照散射，0 跳过积分 |

原有 `UNDERWATER_SURFACE_SOFTNESS` 只用于临界角窗口，已经移除。保存文件中的旧值不会控制现有光学。

## 边界

水体依赖单层屏幕深度，无法重建被遮住或屏幕外的几何。入水深度和水面高度使用有限探针近似，复杂瀑布、多层水面及水面完全离屏时可能不够准确。八步积分也存在有限采样误差，使用平滑场与半分辨率重建缓和；它没有时间历史降噪。

本轮实现、参考与固定场景记录见 [水体改进](20-water-effects.md)。
