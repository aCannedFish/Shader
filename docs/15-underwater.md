# 水下

更新日期：2026-10-10。

## 光程

水下画面在 `composite1` 中统一计算光程，几何阶段保留尚未加水雾的线性光照。水下合成通过不透明场景副本替换透明阶段已经混入的水面颜色，再执行一次水体衰减，避免水面材质与后处理重复叠加。

水的吸收、浑浊度及水下密度共同决定指数衰减。观察水下物体时采用相机到物体的光程；观察水面以上时采用相机到水面的水内光程。浑浊度增加、路径变长时，对比度和可见度下降。

水面几何的线性深度用于估计相机浸入深度；视野不含水面时，以原版天光等级估计。来自天空的散射随深度和当地天光减弱。方块光独立提供照明，熔岩块、熔岩等材质保留自发光，仍会按到相机的水内路径衰减。深水保留有限的最低附近照明与雾底色。默认设置在约 9 个方块内保留透射下限，9–18 个方块之间平滑退出下限，远处继续按光程衰减。该下限用于保留玩家附近物体的辨识能力，不会把深水远景重新照亮。

## 水面

从水下观察水上时，以约 1.333 的折射率计算 Snell 折射方向。折射强度设置同时作用于水上和水下视角。天空及较远物体保留 Snell 窗口，物体采样使用深度迭代修正空气中的距离，拒绝水面下的几何和不收敛的投影。

近景采用保守的屏幕空间近似，避免单层深度无法重建新露出的表面时出现断开的轮廓。物体的折射位移随其高出水面的高度展开，在水面交界处归零，最大位移限制为 56 像素；候选采样必须处于水上，并与原来的深度接近。遇到遮挡或越界时逐步缩小位移，最终只读取一个几何位置。距离界面较近的可见物体还会保留更多透射，减少岸边物体被替换为天空或反射片段的情况。这项近景处理优先保证轮廓连续和游戏可读性。

前景水下物体按不透明深度遮挡水面后处理。透射仅衰减相机到水面的水内光程；内反射按相机到水面、再到反射命中物体的两段光程衰减，完成各自衰减后再合成。临界角过渡区以水体散射承接较弱的内反射，减少两幅清晰物体轮廓同时出现；反射占主导时恢复水下倒影细节。

水下物体、透射物体及内反射全部使用清晰采样，已经移除空间模糊滤波和水下模糊设置。水的浑浊度仍通过吸收、散射和光程影响对比度与可见度。水面以上的天空与云使用同一套环境计算。

当前仍采用单层屏幕深度近似。视角外和被前景遮挡的岸上几何无法被重新生成，此时回退到天空环境；深度估计在完全不含水面、且无天光的视角中也属于近似。

## 边缘

水面透射、反射和高光合成后，使用与陆地一致的距离雾。水体靠近加载范围边缘时逐渐融入地平线颜色，避免光学合成越过原有雾处理后留下亮色的方形截面。

## 白线

在用户截图的坐标附近，以八个方向采集晴天镜头。朝东镜头复现了一条约 203 像素长的竖直亮线。关闭云、星空阶段与日月贴图均未消除它。

将天空程序输出改为纯绿色后，亮线区域保留原来的浅色，说明该处没有被天空网格覆盖。丢弃整层天空时，该区域与背景的对比消失。原始颜色缓冲以显示空间的雾色清除，这个缺口直接露出清除色，经过 HDR 色调映射和显示编码后变亮。

修复将颜色缓冲清除为黑色，并在透明前置与合成阶段，为未被几何或天空覆盖的像素补齐同一条线性空间天空渐变。透明前置的 HDR 场景副本也同步修复，使水面反射不会继承这条缺口。修复的原方向对照中，连续亮线已经消失。

## 参数

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `UNDERWATER_MIN_VISIBILITY` | 0.12 | 深水附近物体的最低可见度 |
| `UNDERWATER_SURFACE_SOFTNESS` | 0.10 | 水下窗口边界的角度过渡范围 |
| `UNDERWATER_DENSITY` | 1.0 | 水下光程衰减倍率 |
| `UNDERWATER_DEPTH_DIMMING` | 1.0 | 随相机深度减弱天光散射 |

水面页面原有的浑浊度、吸收、波浪和颜色参数同样作用于水下。水下的四个选项位于水体页面。

## 验证

```bash
python3 tools/preview.py render --scene underwater_shallow --scene underwater_deep --scene underwater_air
python3 tools/preview.py verify-underwater
```

固定场景包含浅水、深水、浅水看岸上、深水看岸上、熔岩块暗/亮对照与远水镜头。本次增加 `underwater_interface`：一根跨越水面的石英柱，用于检查轮廓连续性及前景遮挡。参数对照保存到 `.preview/underwater-verification/`；调整前后对照保存在 `.preview/underwater-iteration/`。验证覆盖密度、折射强度、深水能见度下限、前景与清晰不透明参考的一致性，以及水底光源。

本次九个实际场景完成离线 GPU 渲染，40 个 Shader 入口通过编译。跨水面测试柱的水下区域与清晰不透明参考的平均误差为 0.023/255；深水场景保留能见度下限时的平均亮度为 12.34，关闭下限后为 2.34。水上反射和暗洞水面与调整前逐像素一致。结果只代表固定测试场景；近景轮廓连续采用上述屏幕空间近似。
