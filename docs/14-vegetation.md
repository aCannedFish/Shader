# 植被

更新日期：2026-10-09。

## 风摆

植被位移集中在 `lib/foliage_wind.glsl`。地形与阴影共用同一份世界坐标函数、动画时间和设置，运动保持在世界中，移动相机不会改变植株的相位。

树叶使用连续空间位移场，将缓慢摆动与较快的小幅颤动叠加。相邻叶片方块的共享顶点得到相同位移，叶团不会裂成独立晃动的小方块。草、花、蕨类、树苗和庄稼以根部为固定支点，位移随高度平方增长，近地部分保持稳定。植株根部哈希错开相位，大尺度阵风和侧向摆动使同一片植物不会同步倾斜。

两格高的草和花分别映射上下部分，上半部分恢复到同一根部高度，接缝顶点使用相同高度曲线和相位。作物直接使用模型高度，幼苗位移自然小于成熟植株。雨天风摆适度增强。

位移场同时作用于表面切向量，叉积恢复变形后的法线，使漫反射光照随植物弯曲变化。

## 阴影

主视图通过 `gbufferModelViewInverse` 恢复世界位置，阴影阶段通过 `shadowModelViewInverse` 恢复世界位置，再调用相同的位移函数。变形在阴影投影和畸变之前进行；主视图用于采样阴影的坐标，也来自已位移的顶点。

阴影片元阶段保留植被贴图的 alpha 测试，叶片和草叶的镂空轮廓参与阴影，避免将整个贴图四边形作为实心投影。

## 覆盖

`block.properties` 使用独立的材质 ID：

| ID | 类型 | 处理 |
| --- | --- | --- |
| 200 | 原版常见树叶 | 连续叶团位移场 |
| 201 | 草、花、蕨类、树苗及软植株 | 单格根部固定 |
| 202 / 203 | 高草、向日葵、玫瑰、牡丹等上下部分 | 共用两格支点与曲线 |
| 204 | 小麦、胡萝卜、马铃薯、甜菜、地狱疣及幼期作物 | 按模型高度减弱幼苗摆动 |

日志中已检查本机 1.21.11 的方块映射。石头、建筑、水和树干保持原位置。自定义资源包仍沿用这些方块 ID，但模型高度和形状会影响实际摆幅。模组植物可在相应 ID 中补充注册名。多格堆叠的甘蔗、竹竿、仙人掌及藤蔓没有归入根部弯曲组，以免逐格移动造成断裂。

## 参数

选项位于光影设置的植被页面：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `ENABLE_FOLIAGE_WIND` | 1 | 植被风摆总开关 |
| `WIND_STRENGTH` | 1.0 | 整体位移倍率 |
| `WIND_SPEED` | 1.0 | 动画速度，0 可冻结风场 |
| `LEAF_SWAY_STRENGTH` | 0.08 | 叶片位移尺度，单位为方块 |
| `PLANT_SWAY_STRENGTH` | 0.18 | 草木顶端的位移尺度 |

风摆关闭时，主视图与阴影同时恢复未变形的位置。风速为 0 时，风场冻结在固定相位；若需要原始形状，应关闭总开关。

## 验证

准备阶段新增植被总览、同机位后续帧、根部近景和阴影近景四个固定镜头，使用真实草、作物、双格花和叶片几何。日常检查运行离线 GPU 重放：

```bash
python3 tools/preview.py render --scene vegetation --scene vegetation_shadows
python3 tools/preview.py verify-wind
```

检查分为两部分。真实 Minecraft 帧比较运动、冻结风场、关闭风摆，以及仅让阴影保持静止时的结果。独立 GPU 变换反馈探针直接执行项目的 GLSL 风函数，检查根部、双格接缝、共享叶片顶点、普通方块、变形法线和主视图/阴影空间的位移一致性。探针不替代真实场景图片。

结果保存到 `.preview/wind-verification/verification.json`。GPU 探针确认根部、双格接缝、共享叶片顶点及普通方块的误差均为 0；不同视图空间恢复后，主视图与阴影位移误差约为 `9e-8` 方块。真实帧的运动平均通道差为 8.06，冻结风场的对照为 0.61；仅停用阴影风摆时，阴影近景产生 0.25 的平均通道差。四个镜头的风摆开关对照均通过。
