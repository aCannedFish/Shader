## 改动

模型筛选先读取方向与染色元数据，再解码匹配候选的几何/UV；固定偏移不重复读取，角点阈值改用平方距离。保持形状、UV、染色和歧义判定。

共享云影采用独立256×256、2米网格，每帧在prepare末尾更新并复制到第二银行。光线投影到云底，保留原五点积分；云内、覆盖外和未初始化区域走原积分。prepare的colortex5采样器单独绑定云噪声，不覆盖原始阴影采集附件。布局schema18。原生读回65536像素无非法值，透射0.82128906–1.0，两银行相同。

NVIDIA的全局inline16限制严重拖慢地形。移除地形限制后原生链接3.418秒，地形31.932→3.405毫秒；prepare移除限制的原生链接1.744秒。新候选只在这两个已核对程序恢复默认编译，保留其他大程序的加载保护。

阴影采集增加三角形包围盒与光源球体的距离排除。它只跳过完全在半径外的几何，范围内的六面投影和阴影格式保持不变。完整候选平均7.284 FPS，prepare4.318毫秒，阴影仍95.910毫秒；该项排除的收益有限，主要收益来自修正过度限制的编译参数。LOW的设置更新预算2与生成后端16不一致，尚未改动，必须同时检查新光源及编辑的延迟。

当前候选621阶段、309/309图形链接通过；12组布局边界及不重叠检查通过。原存档副本0.75内部比例、OptiFine AF=8的原生重载前后缓存均有效、两银行相同；重载后494帧持续45.37秒并正常退出。仍不满足约60 FPS或完整迁移验收，三维度和其他档位不以这些检查代替。

封闭三光源房间的无遮挡、加入石英柱和移除石英柱均原生完成并正常退出。加入柱时地面产生遮挡影，移除后恢复；没有在此基础检查中发现缺影或残影。未做逐像素等价或移动延迟分布的完整验收。
