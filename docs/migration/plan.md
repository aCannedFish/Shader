# 迁移执行计划

## 目标

仅依赖 Minecraft 1.21.11、OptiFine J9 与 macOS 原生 OpenGL 4.1，保留全部效果类别，并系统修复水面与材质反射及局部阴影延迟。效果完整优先；不以关闭功能替代迁移。不使用计算着色器、SSBO、图像原子操作或专用加载器扩展。

正常可绘制的原版场景及现有支持范围内的资源包要求观感完整；隐形命令光源和未提交几何保持原版照明并明确边界。保留适度透明、水色与倒影兼顾、水下可见度。

## 续行

每次读取本文件与 state.json，核对源码和工作区变化，继续最早可执行工作包。只有产物与验证完成才标记已完成。状态：待开始、进行中、待验证、已完成、受阻。每项记录输入基线、源码版本、设置/资源哈希、命令、结果、证据、问题和下一操作。

原始证据持久保存 local-docs/migration；.preview 仅临时。隔离分支实施，原工作区不覆盖。A 使用冻结旧 Shader 与 Mod；B 不加载配套光照 Mod，测试助手只建场景、固定镜头、计时和读回，不能上传运行时世界数据。

## 接口

世界查询区分已知空气、表面、水、透射和未知，并携带有效范围/代次。表面提供形状、法线、反照率、UV、alpha、发光和吸收。光照提供局部能量、独立可见度及间接辐射。反射区分命中表面、确认天空、离开覆盖、步数耗尽和无效输入；后三者不得自动变为天空或黑色。环境查询提供地表、树冠、坡度、露天、水柱与水面天光。

## 管线

阴影阶段采集几何材质 → prepare 更新世界/光源/阴影/GI → 几何基础辐射 → 深度层级 → 统一 SSR 与世界反射 → 水/玻璃/雨/介质 → 泛光与显示。世界近命中否决后方屏幕命中。

最多八个场景颜色附件，颜色/覆盖/雨透射/历史语义分离。布局统一生成，固定尺寸与场景尺寸分开写，明确生命周期、初始化、双缓冲和失效。先验证能力及资源账本，再切换正式路径。

## 验收

场景 S01–S12：坐标/图集/重载；部分形状；叶片后山/墙/天空；混色与满额光源；动态放置移除开关；石英室内反弹与角落；岸线水方块；桥底屋檐屏外；彩色材质倒影；雨水积水玻璃；水下；地形矿石资源与维度。

确定几何先关闭波浪/随机粗糙采样/后处理，再测试完整链路。命中率目标≥99%，错误天空<0.5%；未知单列。边缘容差带单查，不能排除后掩盖白线黑边。颜色与几何误差分开，HDR辐射可>1。旧调用重放不能证明新结构正确，接口/缓冲变动重新原生采集。

新光源几何提交后直接阴影≤3帧；方块状态到首次阴影P95目标≤200ms，主要稳定时间另记，几何上传等待单列。默认GI主要变化约0.5秒，一秒接近新稳态。

同机同视口/视距/设置/热状态交替测静止、走动、转身、水、树林、雨与密光源，记录FPS和帧时间P50/P95/P99、显存和阶段成本。微探针不等同整帧；固定限帧/后台设置。本机M3必测，M3 Max设备可用时补充。

## 执行调整

按用户 2026-10-24 的要求，后续以 Shader 生产和消费路径的编写为主。常规检查限于编译、链接与受修改直接影响的画面，不再为每项不可变数据扩展独立探针或批量读回。必要的性能和最终干净实例验收仍保留。

允许在隔离原型内提前接入后续消费者以推动迁移；阶段完成仍按依赖顺序记录。当前材质路径保留少量细薄模型与动态采集问题，GPU 光源入口已开始实现；这些预实现不视为对应阶段已验收，也不替换正式渲染路径。


## 变更记录
