# 日光散射

近地面日光通过空气中的颗粒散射，在树木、建筑等遮挡之间形成可见光束。实现面向日出、日落的林地和地面场景，默认强度保持克制。

## 光学

沿相机视线积分单次散射。气溶胶使用归一化的 Henyey–Greenstein 前向相函数，并混合较弱的 Rayleigh 项；朝向太阳时更明显，背向太阳时较弱。太阳颜色使用已有大气透射模型，自然随低太阳高度变暖。表面日光使用的 Lambert 归一化在介质积分前转换为入射照度，与每球面度归一化的相函数对应；方向光的体积贡献再使用固定 1.5 倍的画面校准，增强光束而不继续增加消光。

每段积分同时更新 Beer-Lambert 透射率和入散射，以同一段失去的能量计算散射贡献，单次散射反照率取 0.9。已有云层处于近地面空气之后，两者按前后透射率合成，避免简单相加造成白雾叠加。

## 遮挡

每个体积区间在两个深度点投影到真实不透明阴影图 `shadowtex1`，各自在四个阴影纹素中心比较后插值，平均区间的遮挡覆盖。树干、树冠和建筑共同限制入射日照，阴影覆盖之外不补直射光。

云消光在固定高度的 64 个样本上积分，存入按世界网格对齐的二维缓存；射线沿九个固定距离位置查询并插值。云洞的变化不再依赖当前像素的几何深度重排三个稀疏采样点。缓存覆盖 512×512 方块，边缘与极低太阳高度平滑回退。方法与验证见[可见性改进](23-visibility-stability.md)。

积分在不透明几何或水面前终止。半分辨率场重建时比较邻居深度，减少散射越过近处物体轮廓。深度缓冲与有限积分仍有采样误差，不具备全场景体积几何或多重散射。

## 条纹

低角度林地曾出现几条与树干不对应的细长暗线。关闭空气散射后仍能复现；从阴影深度反推的遮挡点落在同一片平地上，属于自阴影误差。

地面阴影的遮挡搜索和滤波改为对齐实际阴影纹素中心，接收面斜率补偿使用该中心相对接收点的真实偏移，并增加半纹素覆盖内的局部深度容差。容差随梯度变化，梯度保持原有上限；同帧对照确认细线消失，主要树影仍保留。体积点继续独立比较遮挡深度。

## 程度

默认 `AIR_SCATTER_STRENGTH` 为 0.65，界面名称为“日光散射强度”，位于世界页面。0 关闭，较高值同时改变衰减与入散射，避免仅抬高亮度。

介质密度联动 `SKY_HAZE` 与 `FOG_DENSITY`，随高度升高而减弱，并在低太阳高度时增加近地面表现。光束内部移除漂移的颗粒噪声，仅保留极低频的静态区域浓度调节；云和几何控制光束运动。相机处于树荫时，前方受光空气仍可散射；封闭空间的入射日光由每段阴影判断限制。积分范围最多 64 方块，在范围末端与加载距离雾接管前渐退；消光系数设有上限。

夜间、水下、岩浆及细雪中跳过该效果；关闭方向阴影时一并关闭，避免产生无依据的光束。日照启停和极低角度的云影回退采用平滑过渡，太阳方向必须与当前阴影光源匹配。没有时间随机噪声或额外高亮粒子。

## 管线

`composite1.fsh` 在空气中计算日光散射，并组合上一通道的体积云；水下保留原日照散射路径。`composite2.fsh` 根据几何深度重建体积场，再以其透射率合成场景。

复用现有 `colortex4`，云体积阴影复用 `colortex3` 的 alpha 区域，未增加纹理附件或渲染通道。每个半分辨率像素最多 32 个固定距离区间，每段读取八个阴影纹素；九次云影查询各读取四个缓存纹素。近处采样更密，几何深度只截短最后一个区间。每段不再读取三维颗粒噪声。`deferred` 的视口由 1/8 扩展到 1/4 宽高以容纳缓存，天空 LUT 的实际尺寸保持 1/8。

## 验证

采集器仅在独立存档副本中固定游戏时间、加快区块更新，并等待网格重建；准备不完整时终止采集。对称林地用于日出、日落、正午、夜间、斜视与轻微相机移动对照；封闭室内、水面和水下镜头检查隔离。实际太阳高度通过 GPU 数据诊断，避免把太阳仍偏高的时刻误当作日出或日落。

```bash
python3 tools/preview.py capture --refresh --world '新的世界 (1)' \
  --scene sunshafts_sunrise --scene sunshafts_sunrise_motion \
  --scene sunshafts_oblique --scene sunshafts_oblique_motion \
  --scene sunshafts_sunset --scene sunshafts_noon \
  --scene sunshafts_night --scene sunshafts_room \
  --scene water_depth_steps --scene underwater_interface
python3 tools/preview.py verify-air
```

该检查比较默认效果、强度为零以及移除日照遮挡的同帧结果，要求低角度效果可见、正午更克制、夜间及水下关闭，且树木遮挡确实改变散射。

验收同时要求正常显示的林地画面具有可见的入散射增亮，以及受遮挡控制的亮束与暗束；单纯整帧变暗或染色不算通过。对照使用连续岩坡背景，并保留日出、日落、正午、室内、夜间、移动及水体检查。

日光散射初次验收的固定镜头检查已通过：42 个着色器入口编译通过，76 项配置校验通过，10 个原始场景重放与客户端截图完全一致。关闭空气散射后，夜间和水下图像差异为零，封闭室内的平均亮度没有上升。

林地斜视镜头中，移除体积阴影后，检查区域的平均通道差为 2.16（8 位显示值），证明遮挡确实改变入散射。正常显示的林地区域有约 38.5% 的像素获得至少 8 级亮度增量；这项数值用于可见性回归，不代表物理测量或性能基准。预览采集限帧为 10，不能据此报告实际游戏帧率。

后续强畸变条件下的阴影深度校正与验证见[阴影映射](05-shadow-mapping.md)。

- Epic Games，[Volumetric Fog](https://dev.epicgames.com/documentation/en-us/unreal-engine/volumetric-fog-in-unreal-engine)：空间介质密度、散射方向与体积阴影的分工，以及通过局部介质增强光束的调节方法。
- Mitchell，[GPU Gems 3 第 13 章](https://developer.nvidia.com/gpugems/gpugems3/part-ii-light-and-shadows/chapter-13-volumetric-light-scattering-post-process)：参与介质中的遮挡产生明暗光束。本项目使用三维阴影采样，避免屏幕径向采样对离屏遮挡的依赖。
- Pharr、Jakob 与 Humphreys，[PBRT 相函数](https://pbr-book.org/4ed/Volume_Scattering/Phase_Functions)：归一化相函数、方向约定与 Henyey–Greenstein 模型。
- Hillaire（2015），[Towards Unified and Physically-Based Volumetric Lighting in Frostbite](https://advances.realtimerendering.com/s2015/index.html)：介质消光、光照与体积合成的工程原则。原始报告见该课程页面的对应演示文稿；本项目采用单次散射近似，没有实现其级联体积架构。
