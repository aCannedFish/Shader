# 可见性改进

本轮调整日落体积光、水下透射、焦散和无光环境的可见度。保留水上观察水底时的原坐标采样，避免重新引入视深折射的断层。

## 体积光

原实现每条视线只在近、中、远三个位置估计云影，每次沿云层取五个样本。低太阳高度使相邻样本间距很大，云洞和几何终点变化容易改变估计结果。光束内部漂移的颗粒噪声还会叠加可见的浓度起伏。

现在先沿太阳方向，以固定云层高度的 64 个样本积分消光，写入天空 LUT 右侧的 alpha 缓存。缓存覆盖 512×512 方块，网格按真实世界纹素大小对齐；查询使用四点插值。`deferred` 的视口宽高改为 1/4，天空 LUT 与云影缓存各占 1/8 宽高，不增加纹理附件或渲染通道。

近地面仍使用最多 32 个固定距离区间。每段在两个深度点查询真实阴影，各执行四个纹素中心的双线性比较，平均沿途遮挡覆盖。九个固定距离节点查询云影，并在区间中连续插值；几何终点只截短最后一段。光束内部使用平稳的高度介质，区域浓度只保留 ±2% 的极低频静态变化。

保留 Beer-Lambert 衰减、前向相函数和深度感知重建。没有加入时间历史，仍受阴影分辨率与有限积分预算限制。

## 水下透射

界面渐变色和环境反射覆盖已移除。水内光程、观察方向与几何世界高度共同区分水上、水下景物。水上部分沿水面交点的波浪偏移，轮廓可以与天空一起移动；水下前景保持原坐标。

偏移上限为 1080p 下 6 像素，随分辨率缩放。只在偏移可能采到水下前景时渐退，水上物体之间的深度差不再锁住轮廓。颜色在真实纹素中心作四点插值，使缓慢波动具有连续的亚像素变化。

## 焦散纹理

焦散采用两个尺度的变形胞元形成流动聚光网，水面波浪与低频形变打散规则边界。亮边使用高斯横截面，保留聚光网内部结构，同时避免硬阈值产生的锐利轮廓。水深、浑浊度略微增加边宽，像素足迹控制远处细节衰减；水底场景颜色不参与空间模糊。

0.1.4 默认 `WATER_CAUSTICS_STRENGTH` 为 0.35，采用当前游戏的调校值。聚光沿折射后的太阳方向投影，受日照、天光、遮挡、接收面朝向与水深调制；夜间无太阳贡献。这是程序纹理近似，没有重建光子传输或真实的水面到池底会聚映射。

本地 Sildur 仅用于研究世界坐标动画、天光与天气约束的分工。当前胞元、高斯亮边、深度分类与采样代码独立编写。

## 基础亮度

新增 `MIN_AMBIENT_LIGHT`，默认 0.07，位于光照页面。它为几何环境光设置最低亮度，独立于日月和原版天光，因此封闭洞穴也保留可导航的暗部。表面朝向和接触遮蔽调整目标值，已经达到目标的光照不继续增加。参数设为 0 可恢复原有暗部。

## 验证

真实 Minecraft 采集包含 18 个镜头：村庄日落与水下跨水面立柱各六帧，日夜浅池、日夜封闭洞穴、村庄地面和阶梯水底。采集仅修改独立存档副本。GPU 重放使用玩家保存的云质量、阴影畸变、饱和度、太阳大小和泛光设置。

42 个 GLSL 入口编译通过，81 项设置与 11 个页面校验通过。下表保留焦散强度为 1.0 时的开发验收对照，数值为 0～255 显示值上的图像测量；0.1.4 的发布默认强度已调整为 0.35。

| 检查 | 结果 |
|---|---|
| 水上景物扰动 | 两个时间点的平均通道差为 4.258、4.091 |
| 水下立柱扰动 | 两个时间点的平均通道差均为 0 |
| 日间焦散 | 池底区域平均通道差为 5.789 |
| 夜间焦散 | 同一区域平均通道差为 0 |
| 封闭洞穴白天 | 平均亮度由 6.43 提高到 23.11 |
| 封闭洞穴夜间 | 平均亮度由 8.15 提高到 29.74 |

体积光测量先减去相同时间的无体积光图像，再对固定区域作浮点空间平均，以减轻八位量化影响。六帧约覆盖一秒。岩坡区域的平均帧间变化由 0.205 降到 0.159，按体积光平均幅度归一化后由 4.14% 降到 3.82%。地面与墙面的绝对变化基本持平，归一化变化略升；这组短序列不证明所有日落云洞中的闪烁均已消除。

预览、对照图、测量脚本与结果保存在 `.preview/visibility-review/`，最终 18 个场景位于 `.preview/visibility-final-v2/`。采集限帧为 10，重放耗时包含工具开销，均不作为实际游戏 FPS 基准。

0.1.4 发布前再次以源码默认值重放全部 18 个场景，确认 81 项默认参数与当前游戏的有效配置逐项一致。焦散强度 0.35 时，池底区域相对关闭焦散的平均通道差为 2.079，夜间为 0；封闭洞穴与村庄地面保持此前验收结果。发布预览与参数核对记录位于 `.preview/release-0.1.4/`。

## 来源

- Hillaire，2015，[Towards Unified and Physically-Based Volumetric Lighting in Frostbite](https://advances.realtimerendering.com/s2015/)：消光场与体积阴影分离。当前只采用缓存消光和单次散射的部分思路，没有实现完整的级联体积系统。
- Bowles 与 Zimmermann，2015，[A Novel Sampling Algorithm for Fast and Stable Real-Time Volume Rendering](https://advances.realtimerendering.com/s2015/)及[原始代码](https://github.com/huwb/volsample)：体积样本在空间中的稳定性。当前固定云层高度和缓存网格，不实现该报告的完整自适应采样算法。
- Epic Games，[Volumetric Fog](https://dev.epicgames.com/documentation/en-us/unreal-engine/volumetric-fog-in-unreal-engine)：体积阴影、介质参数与时间重投影的取舍。当前使用空间过滤，不引入时间历史。
- Sánchez-Crespo，[GPU Gems 第 2 章](https://developer.nvidia.com/gpugems/gpugems/part-i-natural-effects/chapter-2-rendering-water-caustics)：水面波动、入射光方向和焦散过滤的工程分工。本文没有移植其光线映射实现。
- 本地 Sildur `shaders/composite1.fsh` 的 `calcWaves`、`calcBump` 和 `Caustics` 分支；[项目官网](https://sildurs-shaders.github.io/)用于标明参考实现来源。
