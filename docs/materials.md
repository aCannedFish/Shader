# 材质

内置材质直接匹配原版方块，不要求 PBR 资源包。`shaders/block.properties` 声明方块分组，`shaders/lib/materials.glsl` 定义反射率、粗糙度与金属性。未匹配的方块使用原有的粗糙漫反射模型，矿石、泥土、木材、混凝土和织物不会因名称或亮度自动变成金属。

## 分类

粗糙度采用感知粗糙度；数值越大，高光与倒影越宽。F0 是垂直观察时的线性反射率。下表为主体值，贴图亮度会轻微调节粗糙度，并保留金属贴图的明暗纹理。

| 类型 | 方块示例 | 模型 | 粗糙度 | F0 |
| --- | --- | --- | --- | --- |
| 铁 | 铁块、铁门、铁栏杆、铁链 | 导体 | 0.25 | RGB 0.56 / 0.57 / 0.58 |
| 金 | 金块、轻质测重压力板 | 导体 | 0.19 | RGB 0.98 / 0.71 / 0.29 |
| 铜 | 未氧化铜、铜箱及切制、雕纹、涂蜡变体 | 导体 | 0.26 | RGB 0.92 / 0.45 / 0.28 |
| 氧化铜 | 斑驳、锈蚀和氧化铜及其涂蜡变体 | 粗糙介质包覆层 | 0.62 | 0.04 |
| 下界合金 | 下界合金块 | 深色导体 | 0.42 | RGB 0.24 / 0.22 / 0.20 |
| 石英 | 石英块、平滑石英、柱、砖及楼梯、台阶 | 抛光介质 | 0.30 | 0.04 |
| 抛光石材 | 平滑石头、磨制安山岩、闪长岩、花岗岩、黑石等 | 抛光介质 | 0.40 | 0.04 |
| 釉面陶瓷 | 各色带釉陶瓦 | 光滑介质 | 0.22 | 0.04 |
| 黑曜石 | 黑曜石 | 漫反射为主的粗糙介质 | 0.85 | 0.020 |
| 晶体 | 绿宝石块、紫水晶块、紫水晶母岩 | 高折射率介质 | 0.20 | 0.065 |
| 钻石 | 钻石块 | 高折射率介质 | 0.16 | 0.17 |
| 冰 | 冰、霜冰、浮冰、蓝冰 | 光滑介质 | 0.16 | 0.02 |
| 玻璃 | 玻璃、染色玻璃、玻璃板、遮光玻璃 | 薄透明介质 | 0.085 | 0.04 |
| 其他 | 粗糙石材、木材、泥土、矿石、织物等 | 原有漫反射 | 不启用屏幕倒影 | — |

这些是适配方块美术的默认模型，不是对游戏材质进行的物理测量。铜灯按点亮状态区分表面与发光源；火把、灯笼及其他已标记光源继续保留自发光。铜箱等方块实体通过加载器的 `blockEntityId` 接入同一分类；床和木箱等未匹配模型保持原有表面着色。活动实体尚未接入分类，也没有按单个模型的不同面划分金属与非金属。

## 光照

光滑表面使用 GGX 分布、Smith 几何遮蔽和 Schlick Fresnel。介质保持有色漫反射与接近无色的镜面反射；导体以带颜色的反射为主，不额外叠加同等强度的漫反射。全局反射强度也控制这部分能量分配，设为 0 时恢复旧表面外观。

日月高光接收当地天光、方向阴影、玻璃透射色与云影。配套 Mod 可提供有实际方向的点光高光，沿用每个光源自己的遮挡图和玻璃透射数据，不受太阳阴影削弱。没有有效 Mod 或尚未建立遮挡图时，保留原版方块漫反射和环境回退，不凭空生成穿墙的尖锐点光高光。

## 倒影

不透明材质先建立包含低频环境反射的基础辐射，避免金属倒映另一块金属时读到纯黑的中间值。在透明物体绘制前，再使用同一份不可变的场景颜色与深度计算一次屏幕反射，替换相应的基础环境项，最后保存给水面使用。玻璃在透明阶段读取该场景，不读取自己正在写入的附件，避免反馈与反射层反复叠加。

反射使用透视深度步进和七次命中细化。不透明表面的粗糙反射按足迹读取三线性 mip 预过滤，避免稀疏九点把植物轮廓复制为多个错开的像；透明表面的小核过滤保持连续覆盖。屏幕边缘、远端、不可靠命中和背面交点平滑退回环境。主世界不透明表面复用天空与云环境缓存；透明表面采用低成本天空颜色近似。下界、末地使用各自的环境光。当地天光会限制主世界的天空回退，封闭空间另保留原版局部光场的低频辐射。

不透明 HDR 颜色在补天空前以 alpha 保存几何覆盖率，过滤后用它补回天空，避免镂空植物周围出现黑边。环境反射权重使用 GGX 积分的解析近似，前向基础反射和屏幕反射替换共享相同权重，减少粗糙介质在掠射角下过强的镜面观感。`deferred1.fsh` 的三个维度入口使用 GLSL 130 的显式 LOD，其余入口沿用原有版本；硬件基线仍是项目已验证的 OpenGL 4.1。

激活下界传送门使用独立的紫色光源配置。此前缺少这项映射，点光高光使用了近白色回退；现在周围材质的点光高光和漫反射读取相同光色。传送门本身仍走原版透明材质绘制，不把它伪装成镜面中的不透明景物。

点光阴影的接收面外推限制在当前接收距离以内，并按阴影纹素足迹与接收面角度计算有上限的深度补偿。相同规则用于 GI 注入，减轻内角接缝的自遮挡灰斑。独立点光阴影继续保留，没有通过关闭遮挡或大幅抬高环境亮度处理接缝。

玻璃的反射与贴图透明度分别计算：透明贴图内部仍有 Fresnel 反射，边框保留原来的贴图。输出按加载器的普通 alpha 混合换算，避免贴图 alpha 为零时把反射一起丢弃。玻璃不新增景物折射位移；遮光玻璃仍按原版规则阻挡光线。

## 设置

“材质”页面包含：

- `ENABLE_MATERIAL_REFLECTIONS`：开关整套内置模型，关闭后恢复原有表面着色。
- `MATERIAL_REFLECTION_STRENGTH`：反射与能量分配倍率，默认 1.0。
- `MATERIAL_REFLECTION_STEPS`：方块与玻璃的反射步数，默认 24；四档预设分别为 16、24、32、48。
- `ORE_GLOW_STRENGTH`：原矿中矿物像素的自发光强度，默认 0.8，0 关闭；独立于材质反射开关，需要当前配套 Mod。

水面的粗糙度、反射强度与步数仍在“水体”页面独立控制。只有匹配的材质才执行新增反射；大面积金属或玻璃建筑会增加开销。

## 修复验证

2026-10-19 的固定场景覆盖黑曜石、石英与植物、激活下界传送门，以及封闭石英房间的正常、关闭点光阴影、关闭材质反射三组对照，并回归玻璃、水面与水下。测试使用正式存档的独立副本，原存档不接受测试命令；截图属于真实客户端采集，本轮没有 GPU 调用重放。

生产 GLSL 的独立 GPU 测试由 `python3 tools/check_reflection_fixes.py` 执行：高频棋盘经粗糙反射积分后均值为 0.5，透明天空覆盖正确补回背景；32 像素立方体阴影面和半精度深度的解析墙角中，平均可见度由约 0.99508 提高至 0.99971，错误暗像素由 1878 降为 284。该低分辨率压力测试说明自遮挡显著减少，不能解释为任意场景下完全不存在阴影误差。法线、材质编码、GGX 互易性与维度环境另由 `tools/check_materials.py` 检验。

实现参考 [McGuire 与 Mara 的屏幕空间光线追踪论文](https://jcgt.org/published/0003/04/04/paper.pdf)、[Epic 的解析环境 BRDF 说明](https://www.unrealengine.com/blog/physically-based-shading-on-mobile?lang=en-US)和 [NVIDIA 的接收面偏移说明](https://developer.nvidia.com/gpugems/gpugems/part-ii-lighting-and-shadows/chapter-14-perspective-shadow-maps-care-and-feeding)。当前仍是单层屏幕深度近似，不包含被遮挡或屏幕外景物的完整几何重建。

## 矿物

遮罩覆盖煤、铁、铜、金、红石、青金石、绿宝石、钻石的普通及深层原矿，以及下界金矿、下界石英矿，共 18 种。煤矿保持原有受光，其余 16 种按矿物类型发光，铁铜较弱，有色矿物较明显。自发光沿用贴图颜色，在 HDR 表面着色中加入；周围岩石保留原有明暗、遮挡和漫反射模型，整块原矿不变成金属。

配套 Mod 从当前已加载的方块图集读取矿石和对应的石头、深板岩或下界岩贴图。矿物遮罩先排除与整张宿主岩石调色板接近的颜色，再限制有色矿物、浅色石英或深色煤的区域。它不按屏幕亮度猜测，也不直接逐像素相减，因而不会仅因石纹位置不同就整块发亮。遮罩二进制打包到现有光照图集保留行，平常帧不重新生成或上传，资源重载时刷新；不分发 Minecraft 原贴图。

原版 16×16 贴图已验证。支持边长为 64 的约数且不大于 64 的静态正方形矿石贴图；动画、尺寸超限或缺少宿主贴图时关闭相应遮罩，避免低精度遮罩照亮石纹。自定义资源包若改变矿石背景调色板、把矿物与岩石画成同色或修改模型 UV，可能少选、误选或关闭；当前没有显式 PBR 发光图覆盖接口。与宿主颜色过于接近的像素优先不发光。

这是视觉自发光，不改变游戏方块亮度等级，不把每个矿石加入点光阴影或 GI 求解。矿物能在暗处被看到，附近石头仍按真实光照受光；开启泛光时，极亮矿物可出现少量屏幕光晕。旧 Mod、无有效遮罩或关闭配套光照系统时不增加矿物发光。

## 范围

屏幕反射只能使用当前视角已显示的几何；屏外物体、被遮挡表面和透明物体内部无法完整求解。粗糙度过滤是单条光线附近的有限过滤，尚未使用多光线积分、探针场或时域降噪。原版单层深度也限制了玻璃、水面重叠及多层透明物体的正确排序。

当前没有解析 LabPBR 材质图、法线图或各向异性，金属反射率来自内置分类，无法按资源包中的每个像素识别锈蚀与涂层。

模型依据参见 [Filament 材质说明](https://google.github.io/filament/main/filament.html)。
