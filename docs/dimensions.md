# 维度

主世界、下界和末地共用材质、水体、后处理和局部光照程序，分别通过 `shaders/`、`shaders/world-1/` 和 `shaders/world1/` 载入入口。入口只声明维度并引用 `shaders/program/` 下的共享实现，防止三个版本的算法逐渐分叉。

## 下界

下界没有日月直射、日月阴影、主世界云层、太阳光束或太阳镜头光晕。固定暖色环境项保留表面朝向与接触遮蔽，并轻微采用游戏提供的生物群系雾色；玄武岩三角洲、灵魂沙峡谷、诡异森林等区域不会被统一覆盖成相同的红色。

熔岩、火把、菌光体等原版发光方块继续通过当地光照场照明。配套 Mod 的彩色光、独立点光阴影与多次漫反射照常求解；背景环境光不冒充附近熔岩的真实方向或遮挡。封闭处也保留最低可见度，光源附近的亮度独立叠加。

雾按距离连续消光，并在渲染边界前完全收敛到相应方向的背景，隐藏加载边缘。浓度和环境亮度在“世界 → 维度”页面分别调整。

“世界 → 氛围”中的 `NETHER_ATMOSPHERE` 默认 0.65，控制新增的低处暖色层次和缓慢漂移的非均匀烟霭。烟霭使用已有 GI 产生柔和局部辉光，不改变熔岩等光源的真实传播范围。

## 末地

末地使用固定的冷紫色半球环境光、较稀薄的紫色距离雾和稳定的虚空背景。背景的低频色带与少量星点只依赖世界方向，转动相机时没有经度接缝，平移相机也不会让背景贴着玩家移动。

末地不显示主世界太阳、月亮或云层，不随世界的日夜时间改变环境曝光。末地烛、其他发光方块和配套局部光照负责局部明暗；材质反射采用末地的环境颜色。虚空背景是风格化的程序效果，不声称是现实天体的大气模拟。

`END_ATMOSPHERE` 默认 0.65，增加缓慢移动的紫青色星云带、在场景分辨率下抗锯齿的星点、冷色上半球填充和少量近景辉光。水面和材质的环境反射采用同一维度配色；0 恢复基础虚空环境。氛围积分和性能预算见[氛围说明](atmosphere.md)。

## 参数

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `NETHER_AMBIENT` | 0.16 | 下界固定环境亮度 |
| `NETHER_FOG_DENSITY` | 0.02 | 下界距离消光系数 |
| `END_AMBIENT` | 0.14 | 末地固定环境亮度 |
| `END_FOG_DENSITY` | 0.004 | 末地距离消光系数 |

全局 `AMBIENT_STRENGTH`、`MIN_AMBIENT_LIGHT` 与 `FOG_DENSITY` 仍参与相应结果；主世界夜间曝光不用于这两个维度。已保存的用户设置继续覆盖源码默认值。

## 配套光照

0.2.2 Mod 在非主世界停止向 GI 注入日月能量，并使用固定的方向缓存，避免世界时间变化反复重建无贡献的日月数据。独立点光与反弹的接口保持兼容，但需要更新到 0.2.2 Mod 才包含这项维度修正。更换 JAR 后须完整重启客户端。

跨维度时 Mod 丢弃原世界的局部快照并重新采集。数据就绪前使用原版局部光回退，避免将上一维度的照明带入新世界。

维度入口规则参见 [OptiFine 渲染属性](https://github.com/sp614x/optifine/blob/master/OptiFineDoc/doc/shaders.properties)。
