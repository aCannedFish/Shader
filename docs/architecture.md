# 实现

## 管线

Shader 入口采用 OptiFine 程序接口，源文件为 GLSL 120。几何阶段直接计算表面光照；后续通道处理天空查找表、云、水体和后处理。配套 Mod 在客户端主线程队列中执行有预算的场景采集和 GPU 更新，并通过 OptiFine 自定义纹理接口连接 Shader。

| 阶段 | 职责 |
| --- | --- |
| `shadow` | 日月深度与 RGB 透射阴影，使用与地形一致的植被位移 |
| `gbuffers_*` | 几何、材质染色、直接/间接光照及 HDR 场景颜色 |
| `deferred` | 在 1/4 宽高视口内构建 1/8 宽高的天空 LUT、上方的云环境 LUT 与右侧云体积阴影缓存 |
| `deferred1` | 在透明绘制前保存不透明 HDR 场景，补齐天空背景 |
| `gbuffers_water` | 绘制透明水体，记录波浪法线、天光、线性深度与散射参数 |
| `composite` | 半分辨率体积云积分；水下改为一次入水深度估计 |
| `composite1` | 半分辨率近地面日光散射与云合成；水下计算日照散射 |
| `composite2` | 空气与云重建、天空、水面透射与反射、聚光及水下合成 |
| `composite3` | 提取柔和亮部并水平过滤；首个 alpha 保存太阳可见度 |
| `composite4` | 垂直过滤泛光并传递太阳可见度 |
| `final` | 色差、泛光、太阳镜头光晕、夜间暗部曝光、亮度映射、色域约束、颜色调整、暗角与显示编码 |

## 缓冲

| 缓冲 | 用途 |
| --- | --- |
| `colortex0` | HDR 场景颜色与最终场景合成 |
| `colortex1` | 编码法线、天光与材质标记 |
| `colortex2` | 方块光、天光与日月阴影可见度 |
| `colortex3` | 前期天空 LUT、上方云环境 LUT 及右侧 alpha 云体积阴影缓存，后期泛光亮部 |
| `colortex4` | 前期云与近地面散射，或水下散射/路径深度；后期复用为泛光及太阳可见度 |
| `colortex5` | 水面八面体法线、天光可见度与线性视图深度 |
| `colortex6` | 不含透明水面的不透明场景副本 |
| `colortex7` | 水面局部散射辐射与薄层不透明度 |

天空和泛光按阶段复用缓冲，复用发生在旧数据不再被读取之后。水面几何数据与散射附件关闭混合，避免透明颜色混合污染法线和深度。

## 天空

天空使用球壳大气的 Rayleigh/Mie 积分近似，动态天空 LUT 降低逐像素积分成本。日月、星空与地平线使用相同的天空输入。太阳和月亮采用角度圆盘，默认大小近似原版可见亮部，月面带颜色数据与月相。

日月与星点的抗锯齿宽度由投影和视图分辨率估计，避免逐像素深度分支中的未定义屏幕导数。圆盘边缘过滤限制在自身角半径的一小部分，防止日出日落的太阳颜色漏到前景轮廓。

体积云由周期性噪声图集与天气场定义密度，云底、云顶和厚度随位置变化。沿视线积分透射和散射，光照方向采样提供云层自遮挡。主视图使用半分辨率和深度感知重建；默认反射和水下天空读取每帧预建的云环境 LUT，高档位可启用逐反射光线的云积分。云影投影到地面并作用于日月直射。

## 水体

波浪高度场与法线使用绝对世界坐标，维持区块间连续性。水面由透射、吸收、少量散射、Fresnel 反射和 GGX 日月高光合成。屏幕反射在不透明深度上使用透视正确 DDA；无命中时采用受当地天光限制的天空。局部漫反射独立于日月阴影，封闭水域不会仅因太阳位置而获得高亮。

水下前景使用原坐标的不透明副本，水体衰减只应用一次。默认在附近保留有限透射下限，9–18 方块间平滑退出，远处继续衰减。

水上观察水底时不偏移采样，避免岸边断层与抖动。水下观察时，世界高度和水内光程共同区分水上、水下景物；水上轮廓随水面波浪移动，水下前景保持原位置。界面渐变色与内反射覆盖已移除。

焦散用两个尺度的变形胞元模拟不规则聚光网，高斯横截面柔化亮边，水深与像素足迹限制细节。它随时间流动并受日照、水深和遮挡调制。光柱在半分辨率执行八步散射积分，沿水中的太阳方向查询入射阴影，并按深度重建。细节和验证见[水体改进](20-water-effects.md)与[可见性改进](23-visibility-stability.md)。

## 光照

近地面日光散射沿视线积分，入射光受不透明阴影与云影控制。低角度日照增强前向可见性，吸收与散射通过同一套透射率合成，远景雾接管前渐退。半分辨率结果与云按前后关系合成，再深度感知重建；夜间、水下与关闭阴影时跳过。细节见[日光散射](21-sunlight-scattering.md)。

日月直射、天空环境光和局部方块光独立累加。日月阴影只调制对应直射，局部光可以照亮日影和月影中的区域。法线响应独立于原版顶点方向亮度，AO 主要作用于间接项。基础环境亮度为无天光的几何保留可导航的暗部，已有照明达到目标时不再抬亮；表面朝向与接触遮蔽仍然保留。

没有 Mod 数据时使用原版传播光照。配套 Mod 用后台传播的色相体积恢复光色，方块光的基础传播与墙体遮挡沿用原版光场；独立点光阴影进一步调制可见度，GI 单独累加。

原版传播等级换算为方块路径距离后进行平方衰减，Mod 的发光颜色转换为线性辐射；两条路径分别校准近场能量。夜间保持较低的冷色天空基底，暖色方块光独立累加。后处理映射亮度并限制显示色域，减轻绿色增艳与暖光漂白。细节见[光照调色](19-lighting-color.md)。

方向光在片元插值后施加阴影畸变，采用受限的遮挡搜索、半影估计和 PCF 过滤。接收面深度梯度补偿各采样点的深度，并限制基础偏移，减轻自阴影和掠射角的接触偏移。默认档五点搜索、八点过滤，无遮挡时提前结束。细节与限制见[优化记录](18-optimization.md)。

## 局部阴影

Mod 从已加载客户端区块中读取发光方块、地图颜色和 VoxelShape。默认按影响选取最多 32 个点光源，每个光源拥有六面 128×128 线性距离阴影图。片元按光源方向选择立方体面，四点深度比较使用双线性权重与接收平面修正距离，减轻纹素阶梯和掠射地面条纹。

阴影图打包到二维图集，包含光源位置、半径、能量和有效标记。各光源分别查询可见度，再修正其能够解释的原版传播光份额，不共用日月阴影。形状内部完整方块面进行剔除，每张点光阴影图跳过光源自身所在格的遮挡。光源槽位随选择保留，遮挡在光源周围采集；相机或 GI 体积移动不再直接使所有点光阴影失效。新增或移除的光源用约 0.4 秒淡入淡出，近处方块变化优先刷新，远处遮挡约每 4 秒检查。

发光方块具有独立 RGB 配色，透明材质快照另存吸收系数与玻璃板形状。图集 R/G 分别记录不透明和首层玻璃深度，尾部保存每个点光源及日月光到接收位置的 RGB 透射缓存。局部玻璃透射用于点光可见度、GI 注入与跨格传播；日月表面滤色由 Shader 的最近投影体颜色和不透明深度共同决定。细节与边界见[彩色光照](24-coloured-lighting.md)。

## 全局光照

GI 使用第一阶球谐表示 RGB 辐射方向，体素包含反照率、遮挡及天光。直射光照亮的表面注入漫反射辐射，在可通行体素之间传播；后续反弹从上次场中收集入射辐射，乘以材质反照率和反射比例，再重新注入。各次结果累加后发布。

默认体积边长为 32 方块，按玩家位置以四方块步长移动，执行 3 次反弹，每次传播 8 步。阴影与 GI 按预算分摊更新；完成结果双缓冲发布，Shader 不读取未完成的中间反弹。三维场打包为带边界纹素的二维切片，表面查询进行方向重建和插值。

本系统为有遮挡的有限范围漫反射近似。地图颜色不等同于完整纹理反照率，低阶方向表示和有限分辨率会影响细小结构。未覆盖的遮挡类型与平台状态见[兼容说明](compatibility.md)。

## 风摆

树叶、草木和庄稼使用不同的位移权重。根部固定，双格植物按连续高度计算，地形与日月阴影共用位移。局部 Mod 遮挡使用方块快照，因此不能完整匹配贴图镂空与逐顶点风摆。
