# 实现

## 管线

Shader 入口采用 OptiFine 程序接口，源文件为 GLSL 120，使用显式 mip 采样的反射通道采用 GLSL 130。几何阶段直接计算表面光照；后续通道处理天空查找表、云、水体和后处理。配套 Mod 在真实渲染帧开始事件中执行有预算的场景采集和 GPU 更新，并通过 OptiFine 自定义纹理接口连接 Shader。

| 阶段 | 职责 |
| --- | --- |
| `shadow` | 日月深度与 RGB 透射阴影，使用与地形一致的植被位移 |
| `gbuffers_*` | 几何、材质染色、直接/间接光照及 HDR 场景颜色 |
| `deferred` | 在 1/4 宽高视口内构建 1/8 宽高的天空 LUT、上方的云环境 LUT 与右侧云体积阴影缓存 |
| `deferred1` | 不透明材质反射、天空背景及透明阶段所需的 HDR 副本 |
| `gbuffers_water` | 绘制透明水体，记录波浪法线、天光、线性深度与散射参数 |
| `composite` | 可变体积分辨率的云积分（默认半分辨率）；水下改为一次入水深度估计 |
| `composite1` | 同一体积视口内的日光散射、地面雾、维度烟霭与云合成；水下计算日照散射 |
| `composite2` | 空气与云重建、天空、水面透射与反射、聚光及水下合成 |
| `composite3` | 泛光亮部提取与降采样；首个 alpha 保存太阳可见度 |
| `composite4` | 泛光水平过滤并传递太阳可见度 |
| `composite5` | 泛光垂直过滤并传递太阳可见度 |
| `final` | 色差、泛光、太阳镜头光晕、夜间暗部曝光、亮度映射、色域约束、颜色调整、暗角与显示编码 |

## 缓冲

| 缓冲 | 用途 |
| --- | --- |
| `colortex0` | HDR 场景颜色与最终场景合成；天气混合后 alpha 暂存背景透射率，用于一次雾色修正 |
| `colortex1` | RGBA16F；不透明阶段为编码法线、天光与材质标记；透明阶段 R/G 为水面天光与不透明度，B 为雨层亮度矩，A 为水面有效标记加雨层光学深度 |
| `colortex2` | 不透明阶段为方块光、天光、日月阴影与材质数据；透明阶段复用为预乘 HDR 透明颜色与覆盖率 |
| `colortex3` | 前期天空 LUT、上方云环境 LUT 及右侧 alpha 云体积阴影缓存，后期泛光亮部与最终过滤结果 |
| `colortex4` | 前期云与近地面散射及雾，或水下散射/路径深度；后期复用为泛光水平过滤及太阳可见度 |
| `colortex5` | RG 为水面八面体法线，B 为线性视图深度，A 为二值有效标记 |
| `colortex6` | 不含透明水面的不透明场景副本，水面反射前生成 mip 层级 |
| `colortex7` | RGB 为水面局部散射辐射，A 为二值有效标记 |

体积场的生成与深度感知重建共用 `volumeSize()`，低档为四分之一宽高，其余预设默认二分之一宽高。水下在合成入口直接进入水下光学，跳过随后会被覆盖的天空、反射及空气重建。

天空和泛光按阶段复用缓冲，复用发生在旧数据不再被读取之后。水面几何、参数与散射附件使用预乘混合及二值有效标记：水片元直接替换数据，玻璃的零值输出保留已绘制水面。调试模式继续保留原始几何与光照附件。

粒子在不透明后处理之前绘制，避免普通粒子的 G-Buffer 输出覆盖已复用的水面参数。雨丝随后仅向 `colortex1` 的 B/A 加法累积，水面存在与否由 `colortex5.a` 判定；水体和玻璃合成后再恢复雨层，避免水面重建丢失雨幕。详见[雨天说明](weather.md)。

## 天空

天空使用球壳大气的 Rayleigh/Mie 积分近似，动态天空 LUT 降低逐像素积分成本。日月、星空与地平线使用相同的天空输入。太阳和月亮采用角度圆盘，默认大小近似原版可见亮部，月面带颜色数据与月相。

天空和云环境的经度查询在本地缓存区域内循环插值，避免把旁边的云影区域当作环绕边界。

日月与星点的抗锯齿宽度由投影和视图分辨率估计，避免逐像素深度分支中的未定义屏幕导数。圆盘边缘过滤限制在自身角半径的一小部分，防止日出日落的太阳颜色漏到前景轮廓。

体积云由周期性噪声图集与天气场定义密度，云底、云顶和厚度随位置变化。沿视线积分透射和散射，光照方向采样提供云层自遮挡。主视图使用半分辨率和深度感知重建；默认反射和水下天空读取每帧预建的云环境 LUT，高档位可启用逐反射光线的云积分。云影投影到地面并作用于日月直射。

## 水体

水面几何采用较长波浪，逐像素法线叠加短波，并使用连续的世界坐标随机相位打散平行波带。长短波都随像素足迹过滤，掠射时收敛斜率；法线变化率用于增加有效高光粗糙度。相位细节只改变法线，不增加几何位移或纹理采样。倒影读取不透明副本的 mip 层级，四点深度约束核覆盖连续足迹；有效样本不足时平滑退回环境，减少稀疏采样产生的重影轮廓与锯齿。

水面与积水的环境反射使用考虑粗糙度的 GGX 积分权重，避免把粗糙水面当作掠射反射率接近一的理想镜面。法线方差不跨越水体轮廓，离屏回退按反射方向区分天空与下半球，减轻岸线和画面边缘的虚假亮边。

波浪高度场与法线使用绝对世界坐标，维持区块间连续性。水面由透射、吸收、散射、Fresnel 反射和 GGX 日月高光合成。水上观察的散射遮蔽随水内光程累积，默认只在浅水保留清晰的水底，深水逐渐以受当地光照调制的水色和倒影为主；这一密度不用于水下相机。屏幕反射在不透明深度上使用透视正确 DDA；无命中时采用受当地天光限制的天空。局部漫反射独立于日月阴影，封闭水域不会仅因太阳位置而获得高亮。

水体采用低亮度深蓝底色，以间接光为主要照明，少量日月漫射保留明暗变化。环境倒影在正面保留少量贡献，随掠射角度增强，并经过现有粗糙过滤；倒影保留场景颜色，日月高光另行限制强度。

水下前景使用原坐标的不透明副本，先按当地天空与方块光形成低亮度蓝色基调，再合成距离雾。RGB 吸收与各向同性散射共同决定透射，红色衰减更快；默认在附近限制雾遮蔽，9–18 方块间平滑退出，不恢复已吸收的颜色。局部光占优时减弱冷色过滤。

透明方块的颜色与覆盖率另存预乘层。水上根据最近可见透明深度，将其放在水体光学结果之前或之后；水下的原位置与水上景物采样也读取这层，使普通玻璃、染色玻璃和边框保留可见性。天空云层先进入背景，再与玻璃混合。多个水面与玻璃在同一像素前后交错时仍采用单透明层近似。

开放水域的雾色根据相机原生天光做有界曝光补偿，保留深水中的蓝色环境层次。补偿只作用于水下水雾，并受水面天光约束，封闭水域继续由当地光照决定亮度。

相机相关的水下色调与雾色在全屏顶点阶段求值，通过常量插值传入合成片元，避免逐像素重复计算。光柱仍使用既有体积附件和积分步数。

配套 Mod 通过有界水柱查询提供真实入水深度和水面上方的原生天光。查询在相机跨方块或每五个游戏刻刷新一次，不加载新区块。数据保存在现有图集第 7 行的单个纹素；开放水域的深水环境光因此不依赖相机朝向，也不会把封闭洞穴当作白天室外。缺少该元数据时退回水平水面探针和原生相机天光。

水上观察水底时不偏移采样，避免岸边断层与抖动。水下观察时，世界高度和水内光程共同区分水上、水下景物；水上轮廓随水面波浪移动，水下前景保持原位置。界面渐变色与内反射覆盖已移除。

焦散用两个尺度的变形胞元模拟不规则聚光网，高斯横截面柔化亮边，水深与像素足迹限制细节。它随时间流动并受日照、水深和遮挡调制。光柱在半分辨率默认执行八步散射积分，步数可调，沿水中的太阳方向查询入射阴影，并按深度重建。入射光到散射点、散射点到相机的光程共用水下消光系数，使光柱融入水色。

## 光照

雨天的天空、云与日月直射共用连续雨量响应，配套 GI 同步调整日月入射能量。只改变天气亮度时复用原方向的遮挡图，保留局部光源和原更新预算。雨丝及落地水花使用较暗的蓝灰色，雪花保留原色。

地表积水按湿度、朝向、原生天光和地表高度约束，复用不透明单次反射；山林雨雾在既有体积场中增加近地密度，采用低矮的高度衰减和静态低对比度分布。阴雨时减弱方向光束，避免摆动的竖向雾墙。完整规则、开销与限制见[雨天说明](weather.md)。

近地面日光散射沿视线积分，入射光受不透明阴影与云影控制。低角度日照增强前向可见性，吸收与散射通过同一套透射率合成，远景雾接管前渐退。相机固定的密度调节在全屏顶点阶段求值；云影标量缓存用一次线性读取完成插值。半分辨率结果与云按前后关系合成，再深度感知重建；夜间、水下与关闭阴影时跳过。

日月直射、天空环境光和局部方块光独立累加。日月阴影只调制对应直射，局部光可以照亮日影和月影中的区域。法线响应独立于原版顶点方向亮度，AO 主要作用于间接项。基础环境亮度为无天光的几何保留可导航的暗部，已有照明达到目标时不再抬亮；表面朝向与接触遮蔽仍然保留。

没有 Mod 数据时使用原版传播光照。配套 Mod 用后台传播的色相体积恢复光色，方块光的基础传播与墙体遮挡沿用原版光场；独立点光阴影进一步调制可见度，GI 单独累加。

原版传播等级换算为方块路径距离后进行平方衰减，Mod 的发光颜色转换为线性辐射；两条路径分别校准近场能量。夜间保持较低的冷色天空基底，暖色方块光独立累加。后处理映射亮度并限制显示色域，减轻绿色增艳与暖光漂白。

方向光在片元插值后施加阴影畸变，采用受限的遮挡搜索、半影估计和 PCF 过滤。接收面深度梯度补偿各采样点的深度，并限制基础偏移，减轻自阴影和掠射角的接触偏移。默认档五点搜索、八点过滤，无遮挡时提前结束。

## 局部阴影

Mod 从已加载客户端区块中读取发光方块、地图颜色和 VoxelShape。默认按影响选取最多 32 个点光源，每个光源拥有六面 128×128 线性距离阴影图。片元按光源方向选择立方体面，四点深度比较使用双线性权重，并按阴影命中面的轴向和平面距离比较遮挡，避免墙面与地面接缝处把相邻接收面误判为遮挡物；旧 Mod 数据回退为接收平面修正距离。

阴影图打包到二维图集，包含光源位置、半径、能量和有效标记。各光源分别查询可见度，再修正其能够解释的原版传播光份额，不共用日月阴影。形状内部完整方块面进行剔除，每张点光阴影图跳过光源自身所在格的遮挡。光源槽位随选择保留，遮挡在光源周围采集；相机或 GI 体积移动不再直接使所有点光阴影失效。新增或移除的光源用约 0.4 秒淡入淡出，近处方块变化优先刷新，远处遮挡约每 4 秒检查。

遮挡复查先分片读取方块状态指纹，状态未变时复用已有网格和阴影图。相机移动引起的快照边缘变化也经过此验证；接收位置相关的玻璃透射缓存继续单独更新。真正重建网格时，先统计可见面，再一次分配精确长度的顶点数组，保持原有顶点顺序和遮挡形状。性能检查与测量范围见[性能说明](performance.md)。

快照验证阶段的完整方块使用占用数组表示，仅在场景需要上传时展开为原有几何。地形雾与光照元数据按内容变化提交，静止时复用已有纹理。

发光方块具有独立 RGB 配色，透明材质快照另存吸收系数与玻璃板形状。图集 R/G 分别记录不透明和首层玻璃深度，点光阴影区域的 B/A 记录不透明命中面的轴向及相对光源的有符号平面距离，尾部保存每个点光源及日月光到接收位置的 RGB 透射缓存。局部玻璃透射用于点光可见度、GI 注入与跨格传播；日月表面滤色由 Shader 的最近投影体颜色和不透明深度共同决定。

## 全局光照

GI 使用第一阶球谐表示 RGB 辐射方向，体素包含反照率、遮挡及天光。直射光照亮的表面注入漫反射辐射，在可通行体素之间传播；后续反弹从上次场中收集入射辐射，乘以材质反照率和反射比例，再重新注入。各次结果累加后发布。

默认体积边长为 32 方块，按玩家位置以四方块步长移动，执行 4 次反弹，每次传播 8 步。阴影与 GI 按预算分摊更新；完成结果双缓冲发布，Shader 不读取未完成的中间反弹。三维场打包为带边界纹素的二维切片，表面查询进行方向重建和插值。

本系统为有遮挡的有限范围漫反射近似。地图颜色不等同于完整纹理反照率，低阶方向表示和有限分辨率会影响细小结构。未覆盖的遮挡类型与平台状态见[兼容说明](compatibility.md)。

## 风摆

树叶、草木和庄稼使用不同的位移权重。根部固定，双格植物按连续高度计算，地形与日月阴影共用位移。叶片法线由位移场的解析导数计算，植株复用当前位移计算高度方向变化，减少重复风场与哈希运算。局部 Mod 遮挡使用方块快照，因此不能完整匹配贴图镂空与逐顶点风摆。

薄植被的日月逆光透射由最近投影体的类别与厚度限制，实体墙和厚叶团不透光。普通表面仍按不透明叶片接收阴影；效果不改变方块 alpha。当前为有界的单层近似。

## 材质

`deferred1` 在透明绘制前为选定材质加入单次反射，再保存不透明 HDR 场景到 `colortex6`。地形与方块实体共用同一分类，方块实体由 `blockEntityId` 提供类别。`colortex2.a` 保存材质类别与 16 级贴图亮度，RGB 仍保留光照信息；`colortex1.rg` 改为八面体法线编码，能够还原完整法线半球。透明材质读取不可变的不透明场景，单独换算 Fresnel 与透明混合。实现边界与分类表见[材质说明](materials.md)。

## 维度

三个维度的入口引用 `program/` 下的同一实现。`SIMPLE_DIMENSION` 在入口编译时固定：0 主世界、-1 下界、1 末地。环境、雾、天空与直射光使用这一标记；局部光、GI、水体和后处理保留共用路径。配套 Mod 另按真实世界键停止非主世界的日月 GI 注入，详见[维度说明](dimensions.md)。

## 氛围

`TerrainFogCache` 按预算采集原生地表高度、群系与天空/方块光，存入现有 `companionAtlas` 的保留行 1–6；第 7 行存放水下相机元数据。场景坐标采用相机相对原点，噪声使用真实世界模坐标，兼容加载器浮动原点。`composite1` 中的近景介质与日光散射按光学深度合并，限制透射下限并复用 `colortex4`。云和雾用 `depthtex1` 约束不透明背景，再由 `colortex5` 的水面深度截断，避免透明玻璃成为背景体积的错误终点。

极光在球壳中积分并写入已有天空 LUT；晨昏色带与天空、露天表面和云层环境项保持一致。末地星云在天空缓存计算，星点在场景分辨率求值。具体参数与范围见[氛围说明](atmosphere.md)。

## 矿物

`OreGlowMasks` 比较当前块图集的矿石与宿主岩石颜色集合，在资源重载时生成 18 份 64×64 二进制遮罩。每 RGBA16F 纹素打包 32 个位，使用精确 0–255 字节数值，存入 `companionAtlas` 第 8 行开始的保留区域；图集 UV 原点分成高位和残差，保留半浮点下的子纹素精度。共享地形片元在对应矿物像素加入 HDR 自发光，不修改原生发光等级与点光源集合。无有效遮罩时关闭发光。资源包限制见[材质说明](materials.md)。
