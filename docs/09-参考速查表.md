## 1. GLSL 120 速查

### 类型

```glsl
float  int  bool
vec2  vec3  vec4        // 向量
mat2  mat3  mat4        // 矩阵（按【列】主序）
sampler2D               // 纹理句柄（只能声明，不能赋值）
```

浮点必须带小数点：`1.0` 不是 `1`。

### 构造

```glsl
vec3 v = vec3(1.0, 0.5, 0.2);
vec4 c = vec4(v, 1.0);            // 用 vec3 补一个分量
vec3 x = vec3(someVec2, 0.0);     // 用 vec2 补一个分量
vec3 f = vec3(1.0);               // 广播：(1,1,1)
mat3 r = mat3(gbufferModelView);  // 取 4x4 的左上 3x3
```

### 分量

```glsl
c.rgb  c.a       // 颜色
v.xyz  v.w       // 坐标
uv.xy            // 纹理坐标
c.bgra           // 任意重排
v.xy * 2.0       // 也可以直接当向量用
```

（`rgba` / `xyzw` / `stpq` 三套等价，**同一个表达式里不能混用**。）

### 运算符

```glsl
a * b        分量对应相乘（不是矩阵乘法）
m * v        矩阵 × 向量
v * m        向量 × 矩阵（注意顺序）
-v           取反
```

**矩阵乘法顺序不能交换**：`m1 * m2 * v` 表示"先对 v 应用 m2，再应用 m1"。

### 常用函数

| 类别 | 函数 |
|------|------|
| 角度 | `radians(deg)` `degrees(rad)` `sin` `cos` `tan` `asin` `acos` `atan(y,x)` |
| 幂/指数 | `pow(x,y)` `exp(x)` `log(x)` `sqrt(x)` `inversesqrt(x)` |
| 常用 | `abs` `sign` `floor` `ceil` `fract` `mod(x,y)` `min` `max` `clamp(x,a,b)` `mix(a,b,t)` |
| 插值 | `step(edge,x)` `smoothstep(e0,e1,x)` |
| 几何 | `length(v)` `distance(a,b)` `dot(a,b)` `cross(a,b)` `normalize(v)` `reflect(I,N)` `refract(I,N,eta)` `faceforward` |
| 纹理 | `texture2D(sampler, uv)` `texture2D(sampler, uv, bias)` |
| 导数 | `dFdx(x)` `dFdy(x)` `fwidth(x)`（片元着色器专用） |

### GLSL 120 的限制

```glsl
// ❌ 循环上界不能是变量
for (int i = 0; i < someUniformInt; i++) {}
// ✅ 必须是编译期常量
for (int i = 0; i < 4; i++) {}
for (int i = -SHADOW_SOFTNESS; i <= SHADOW_SOFTNESS; i++) {}   // SHADOW_SOFTNESS 是 #define

// ❌ 没有 switch、没有数组初始化列表、没有 bit 运算
// ✅ if/else、while 都可以
```

### 限定符

```glsl
#version 120                                     // 必须第一行

vec4 position = gl_Vertex;                        // 顶点数据（仅 .vsh）
uniform   mat4 gbufferModelView;                 // 全局常量
varying   vec2 vTexCoord;                        // .vsh 输出 / .fsh 输入
const     float PI = 3.14159265;                 // 编译期常量

gl_Position    // .vsh 唯一必须写的东西
gl_FragCoord   // .fsh：像素坐标 (x, y, depth)
gl_FragData[n] // .fsh：第 n 个渲染目标的输出
discard;       // .fsh：丢弃当前像素
```

### 其它

```
shadow                阴影贴图通道

composite ~ composite15   编号的后处理通道

```

### 每个程序的必备结构

```glsl
// .vsh
#version 120
#include "..."
attribute ...;
varying ...;
void main() { ... }          // 必须写 gl_Position

// .fsh
#version 120
#include "..."
uniform sampler2D ...;
varying ...;
void main() { ... }          // 写 gl_FragData[n]
```

`composite` / `composite1` / ... 的 `.fsh` **必须**有：

```glsl
/* RENDERTARGETS: 0,1 */     // 写在文件里，OptiFine 会扫描这个注释
```

## 3. OptiFine uniform 速查

### 矩阵

| 名字 | 类型 | 含义 |
|------|------|------|
| `gbufferModelView` | mat4 | 世界 → 视图（玩家摄像机） |
| `gbufferModelViewInverse` | mat4 | 视图 → 世界 |
| `gbufferProjection` | mat4 | 视图 → 裁剪 |
| `gbufferProjectionInverse` | mat4 | 裁剪 → 视图 |
| `gbufferPreviousModelView` | mat4 | 上一帧的 modelView（TAA 用） |
| `gbufferPreviousProjection` | mat4 | 上一帧的 projection |
| `shadowModelView` | mat4 | 世界 → 太阳视图 |
| `shadowModelViewInverse` | mat4 | 太阳视图 → 世界 |
| `shadowProjection` | mat4 | 太阳视图 → 裁剪 |
| `shadowProjectionInverse` | mat4 | 太阳裁剪 → 视图 |

### 摄像机与屏幕

| 名字 | 类型 | 含义 |
|------|------|------|
| `cameraPosition` | vec3 | 摄像机绝对世界坐标 |
| `previousCameraPosition` | vec3 | 上一帧的摄像机位置 |
| `near` / `far` | float | 近/远平面距离（`far` = 渲染距离） |
| `viewWidth` / `viewHeight` | float | 渲染分辨率（像素） |
| `aspectRatio` | float | 宽高比 |
| `centerDepthSmooth` | float | 屏幕中心深度（景深用） |

### 光照与天空

| 名字 | 类型 | 含义 |
|------|------|------|
| `sunPosition` | vec3 | 太阳方向（**视图空间**，长度约 100） |
| `moonPosition` | vec3 | 月亮方向（视图空间） |
| `shadowLightPosition` | vec3 | 当前投影光源方向（白天=太阳） |
| `upPosition` | vec3 | 世界"上"方向在视图空间中的表示 |
| `skyColor` | vec3 | 天空颜色 |
| `fogColor` | vec3 | 地平线雾颜色；类型不匹配会触发 OpenGL 1282 |
| `fogDensity` | float | 雾浓度 |
| `sunPathRotation` | const float | 太阳轨迹倾斜角（度） |

### 环境与时间

| 名字 | 类型 | 含义 |
|------|------|------|
| `worldTime` | int | 游戏内时间 `[0, 24000)`，6000 = 正午 |
| `worldDay` | int | 游戏天数 |
| `frameTimeCounter` | float | 累计秒数（做动画用） |
| `frameCounter` | int | 帧序号 |
| `moonPhase` | int | 月相 0~7 |
| `rainStrength` | float | 雨强度 `[0,1]` |
| `wetness` | float | 地表湿度 `[0,1]` |
| `eyeAltitude` | float | 摄像机 y 坐标 |
| `eyeBrightnessSmooth` | ivec2 | 所在位置的方块光、天空光，经过平滑 |
| `isEyeInWater` | int | 0=空气 1=水 2=岩浆 3=细雪 |
| `nightVision` / `blindness` | float | 状态效果强度 |
| `screenBrightness` | float | 游戏亮度设置 |
| `alphaTestRef` | float | 当前 alpha 测试阈值 |
| `entityColor` | vec4 | 实体叠加色（受伤闪红），`a` 是强度 |
| `atlasSize` | float | 方块图集边长（像素） |

### 纹理

| 名字 | 内容 |
|------|------|
| `texture` | 方块/物品图集 |
| `lightmap` | 光照贴图（16×16） |
| `normals` | 法线贴图（如果资源包提供了） |
| `specular` | 高光贴图 |
| `shadowtex0` / `shadowtex1` | 阴影深度贴图；`shadowMap` 不是自动绑定名 |
| `noisetex` | 噪声纹理（分辨率由 `noiseTextureResolution` 决定） |
| `colortex0` ~ `colortex15` | 渲染目标 |
| `depthtex0` | 深度（含所有物体） |
| `depthtex1` | 深度（不含半透明） |
| `depthtex2` | 深度（不含半透明和手持物品） |

### 顶点属性

本项目的 GLSL 120 程序使用兼容配置。`gl_*` 是这里实际使用的输入；
`va*` 属于 core 配置，地形的 `vaPosition` 还需要区块偏移，不能直接替换。

| 名字 | 类型 | 含义 |
|------|------|------|
| `gl_Vertex` | vec4 | 模型空间顶点位置 |
| `gl_Normal` | vec3 | 模型空间法线 |
| `gl_Color` | vec4 | 顶点颜色（含生物群系染色） |
| `gl_MultiTexCoord0` | vec4 | 图集坐标，经 `gl_TextureMatrix[0]` 变换 |
| `gl_MultiTexCoord1` | vec4 | 光照坐标，经 `gl_TextureMatrix[1]` 变换 |
| `mc_Entity` | vec2 | 方块/实体 ID + 渲染类型 |
| `mc_midTexCoord` | vec2 | 当前方块面中心的 UV（材质判断用） |

## 4. Shader Constants（写在 `settings.glsl` 里的 `const`）

```glsl
const int   shadowMapResolution       = 2048;    // 阴影贴图分辨率
const float shadowDistance            = 96.0;    // 阴影覆盖距离（方块）
const float shadowDistanceRenderMul   = 1.0;     // 阴影渲染距离倍率
const bool  shadowHardwareFiltering   = false;   // 硬件深度比较过滤
const float sunPathRotation           = 0.0;     // 太阳轨迹倾斜角
const int   noiseTextureResolution    = 64;      // 噪声纹理分辨率
const float wetnessHalflife           = 200.0;   // 湿度衰减半衰期
const float drynessHalflife           = 75.0;    // 干燥半衰期
const float eyeBrightnessHalflife     = 10.0;    // 位置亮度平滑半衰期

// 每个颜色缓冲区的格式与清除行为
const int  colortex0Format      = RGBA16F;   // RGBA8 / RGB8 / RGBA16F / RGB16F / RGBA32F ...
const bool colortex0Clear       = true;      // 每帧是否清除
const bool colortex0MipmapEnabled = false;   // 是否生成 mipmap
```

格式可选值：
`R8 R16 R16F R32F RG8 RG16 RG16F RG32F RGB8 RGB16 RGB16F RGB32F RGBA8 RGBA16 RGBA16F RGBA32F R11F_G11F_B10F`


## 6. 常用代码片段

### 坐标变换链

```glsl
// 模型 -> 视图，矩阵包含当前区块或实体的变换
vec4 viewPos = gl_ModelViewMatrix * gl_Vertex;

// 视图 -> 世界(摄像机相对)
vec3 worldPos = (gbufferModelViewInverse * vec4(viewPos.xyz, 1.0)).xyz;

// 视图 -> 绝对世界
vec3 absolutePos = worldPos + cameraPosition;

// 视图 -> 裁剪
vec4 clipPos = gl_ProjectionMatrix * viewPos;

// 裁剪 -> UV
vec2 uv = clipPos.xy / clipPos.w * 0.5 + 0.5;

// 屏幕 UV -> 视图（需要深度）
vec4 ndc = vec4(uv * 2.0 - 1.0, depth * 2.0 - 1.0, 1.0);
vec4 v = gbufferProjectionInverse * ndc;
vec3 viewPosFromDepth = v.xyz / v.w;
```

### 阴影坐标（顶点着色器）

```glsl
vec4 shadowClipPos = shadowProjection * shadowModelView * gbufferModelViewInverse * viewPos;
shadowClipPos.xyz = distortShadow(shadowClipPos.xyz);   // 畸变必须在透视除法前
vShadowClipPos = shadowClipPos;
```

### 深度线性化

```glsl
float linearizeDepth(float depth) {
    float ndc = depth * 2.0 - 1.0;
    return (2.0 * near * far) / (far + near - ndc * (far - near));
}
```

### 法线编码

```glsl
vec2 encodeNormal(vec3 n) { return n.xy * 0.5 + 0.5; }
vec3 decodeNormal(vec2 e) {
    vec2 xy = e * 2.0 - 1.0;
    return vec3(xy, sqrt(max(1.0 - dot(xy, xy), 0.0)));
}
```

### 安全归一化

```glsl
vec3 safeNormalize(vec3 v, vec3 fallback) {
    float len = length(v);
    return len > 1e-5 ? v / len : fallback;
}
```

### 感知亮度

```glsl
float luma(vec3 color) { return dot(color, vec3(0.2126, 0.7152, 0.0722)); }
```

### 软阈值（泛光）

```glsl
float brightness = luma(color);
float contribution = max(brightness - THRESHOLD, 0.0) / max(brightness, 1e-5);
color *= contribution;
```

### 屏幕 UV

```glsl
vec2 screenCoord = gl_FragCoord.xy / vec2(viewWidth, viewHeight);
```

### 伪随机

```glsl
float hash12(vec2 p) { return fract(sin(dot(p, vec2(12.9898, 78.233))) * 43758.5453); }
```

### 抖动

```glsl
float noise = texture2D(noisetex, screenCoord * vec2(viewWidth, viewHeight) / 64.0).r;
noise = fract(noise + float(frameCounter) * 0.618);   // 每帧换图案
color += (noise - 0.5) / 255.0;
```

### 高斯权重

```glsl
float weight = exp(-distSq / (2.0 * sigma * sigma));   // distSq = x² + y²
```

## 7. 数值参考

| 参数 | 常用范围 | 说明 |
|------|---------|------|
| `shadowMapResolution` | 1024 ~ 4096 | 2 的幂 |
| `shadowDistance` | 64 ~ 192 | 越大阴影越糊 |
| `SHADOW_MAP_BIAS` | 0.0 ~ 0.95 | 0.0 = 不畸变，越大越向近处集中 |
| `SHADOW_BIAS` | 0.0001 ~ 0.001 | 太大会悬空 |
| `SHADOW_SOFTNESS` | 0 ~ 2 | 采样数 (2n+1)² |
| 高斯 `sigma` | 半径的一半 | 模糊核 |
| 高光 `glossiness` | 20 ~ 1000 | 越大越锐利 |
| `BLOOM_THRESHOLD` | 0.7 ~ 1.2 | 越低越容易发光 |
| `EXPOSURE` | 0.6 ~ 1.5 | 1.0 = 不变 |
| `SATURATION` | 0.8 ~ 1.25 | 1.0 = 不变 |
| 雾起始位置 | `far * 0.55` | 越小雾越近 |
| 太阳高度过渡区间 | `-0.05 ~ 0.10` | 昼夜过渡带 |
