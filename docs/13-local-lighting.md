# 局部光照

更新日期：2026-10-10。

## 问题

床、箱子等方块实体经过 `gbuffers_block`。此前该程序被误当作选中框和挖掘裂纹程序，直接输出材质颜色，导致白色床在夜晚保持很高的亮度。现在方块实体与地形共用环境光、方块光、日月直射和雾计算；非发光材质不会因为贴图偏白而获得自发光。

云原有固定的夜间环境项为 0.14，随后还会累加月光，白色云面因此过亮。夜间环境项降至 0.004，月光单独校准，并增加夜云亮度控制。云的形状、半透明度和运动保持原有算法。

## 方案

光照按线性空间辐射相加。日月阴影只限制对应的直射项，局部光不经过日月阴影系数。附近火把增加局部辐射后，受日月遮挡处仍会变亮；阴影的可见反差取决于被挡直射光在总照明中的比例。

当前组合为：

```text
表面颜色 = 反照率 ×（天空散射 × AO
                      + 局部光 × 弱 AO
                      + 日月直射 × 日月可见度）
           + 材质自发光
```

对非光追方案做了以下筛选：

| 方法 | 条件与取舍 | 本次采用 |
| --- | --- | --- |
| 每个局部光源使用阴影图 | 可以得到方向明确的投影，需要光源列表与额外阴影渲染调度；点光源通常使用立方体阴影图 | 未加入 |
| LPV 光照传播体 | 适合低频间接光，需要体积存储、光源注入、几何遮挡与多次传播；它仍需要另行处理局部直射阴影 | 未加入 |
| 原版传播场与独立照明 | 已有方块光等级包含墙体遮挡与距离传播，兼容当前 OptiFine 与 OpenGL 4.1；缺少逐光源方向信息 | 采用 |

本次主要修正第三种方案的亮度标定。以前把游戏的显示用光照贴图曲线直接变成局部辐射，再额外加入日月直射，两者的强度关系不稳定。现在用原版连续方块光等级估计有效传播距离，只从光照贴图读取光源色相，照明强度使用独立的有界衰减：

```text
q = 1 − 方块光等级 / 15
局部光衰减 = (1 − q⁴)² / (1 + 衰减参数 × q²)
```

该曲线借鉴实时点光源的平滑范围截止。此处的 `q` 是传播距离代理，缺少真实光源坐标，因此属于近似，不能等同于物理距离平方反比。零等级严格输出零，附近受光处平滑变亮，不解除墙体遮挡，也不人为删除日月阴影图。

月光从原先日光倍率的 0.075 改为独立的默认强度 0.018。夜间天空散射也降低，避免无光源环境掩盖局部照明。水体、普通实体、手持模型和方块实体共用这一组日月与局部光参数。水下的最低附近可见度仍由水体设置单独保留。

## 平滑

`oldLighting=false` 关闭游戏预先写入顶点 RGB 的固定方向暗化，`separateAo=true` 将地形环境遮蔽放到顶点 alpha。天空散射保留 AO，局部光仅保留较弱的 AO，减少附近发光体照亮后仍带着很重的烘焙暗斑。

方块光等级沿模型表面插值，再逐片元计算连续衰减。天空光和基础暗光仍在线性空间中进行四纹素插值。关闭平滑选项可查看离散等级对照。材质纹理不会被光照平滑处理模糊。

## 参数

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `SUNLIGHT_STRENGTH` | 1.0 | 日光直射强度 |
| `MOONLIGHT_STRENGTH` | 0.03 | 月光直射强度，独立于日光 |
| `BLOCK_LIGHT_STRENGTH` | 2.0 | 方块光强度 |
| `BLOCK_LIGHT_FALLOFF` | 6.0 | 局部光外围衰减，值越大，外围越暗 |
| `SMOOTH_BLOCK_LIGHT` | 1 | 连续方块光等级与天空光采样 |
| `CLOUD_NIGHT_BRIGHTNESS` | 1.0 | 夜间云照明倍率 |

前五项位于光照页面，夜云亮度位于世界页面。

## 验证

增加床的白天、夜间、火把照明镜头，以及同一石柱地面的白天和夜间无光源/有火把对照；另保留夜云镜头。

```bash
python3 tools/preview.py render --scene lighting_bed_night --scene lighting_shadow_night_lit --scene clouds_night
python3 tools/preview.py verify-lighting
python3 tools/preview.py verify-materials
```

`verify-lighting` 通过世界坐标重建分离床面、旁边白色羊毛顶面与火把附近的中性地面。它检查非发光材质的昼夜响应、火把照明响应，并在完全相同的帧中仅关闭日月阴影作为对照，比较局部光加入前后的阴影相对反差。云检查分离云表面辐射与天空背景，避免背景亮度影响结果。

本次实际 GPU 检查中，夜间床面平均显示亮度为 29.67，旁边白色羊毛为 29.20，两者比值 1.016。火把加入后，受遮挡地面对“关闭日月阴影”同帧对照的相对亮度损失，白天从 26.9% 降到 3.2%，夜间从 17.6% 降到 0.064%。云表面平均显示亮度为白天 213.02、夜间 13.15；这些数值是固定场景的显示像素统计，并非照度单位。

GPU 检查的结果保存到 `.preview/lighting-verification/verification.json`。原有水体材质、洞穴漏光与平滑光照验证继续保留并通过：封闭洞穴三个日夜对照中的日月光泄漏差异均为零，连续局部光的边缘能量由离散等级的 2.488 降到 1.432，降低约 42%。这些边缘统计排除了材质纹理和光源自身。

## 伴随模块

可安装 [伴随光照](17-companion-lighting.md)，启用独立点光阴影和多次漫反射体积。未安装或关闭模块时使用本文的原版传播场方案。夜间可见度新增环境亮度与曝光控制。

## 回退限制

当前局部光使用 Minecraft 的最大等级传播场。它能近似墙体遮挡和扩散照明，多个光源的重叠区域也受原版传播规则影响。此实现尚未为每个火把建立独立阴影图，无法提供精确的逐光源投影或完整的多次反弹全局光照。强日光仍可能留下少量可见阴影反差，这是独立照明累加后的结果。
