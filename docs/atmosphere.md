# 氛围

0.2.2 加入地面雾、夜间极光、晨昏色带，以及下界烟霭和末地星云。这些效果可以在“世界 → 氛围”分别调整或关闭；环境基础亮度和远景雾仍在原来的页面调整。

## 地面雾

地面雾跟随真实地表，在森林、树冠下及起伏山坡生成，晨昏、夜间和雨天较明显。密度随离地高度指数衰减，低频噪声形成缓慢移动的薄雾。它不在固定世界高度铺设平面，近处逐渐淡出，单独一层最多遮蔽 55%，保留地形与道路的可读性。

配套 Mod 按每帧 96 列的预算读取已加载区块，在玩家附近缓存 65×65 个采样点，间距为 4 方块。它剥离树冠与树干后寻找地表，记录群系、天空光和方块光；树干所在列从相邻空气补采光照。森林、针叶林、丛林、树冠与高度梯度共同决定生境权重。没有天空光的室内或地下列、尚未加载的区块不生成雾。网格移动时保留重叠数据，边缘和新世界逐渐淡入。

雾光照包含天空、晨昏环境、受日月阴影和云影限制的直射，以及地表附近的方块光。它是低分辨率地形近似，不能精确贴合每处台阶、建筑屋檐、悬崖和多层洞口；场景远边由原来的距离雾衔接。旧 Mod 或关闭“配套光照系统”时，这层雾自动关闭。

## 极光

晴夜的北侧天空出现两道连续、缓慢起伏的发光幕。极光在 90–150 千米的球壳中有限步积分，使用程序噪声调节轮廓与细束，不增加贴图。绿青色主体与少量红紫色高处边缘采用风格化配色；它不是按地理磁场或粒子输运进行的物理求解。

暮光、月相、降雨、观察方向和云遮挡共同限制可见度。全雨时发光项保留晴天的 5%；白天、地平线以下、下界和末地关闭。强度默认 0.8，速度为 0 时冻结形态。动画周期与加载器的一小时计时回绕对齐，避免整点突然跳变。

极光在小尺寸天空缓存中计算，水面与不透明材质环境反射复用同一天空；不会为每个屏幕像素重新积分。薄束细节受缓存分辨率与有限采样限制，低档画质更柔和。

## 晨昏

日出、日落时，在现有大气散射上增加朝日暖色地平线与背日粉紫色带，并给露天表面和云层加入适量半球环境色。颜色随太阳高度连续变化，太阳接近地平线时较明显，正午和深夜自然减弱。封闭空间不会仅因时间变化获得这层天空照明。

`TWILIGHT_STRENGTH` 默认 0.7，设为 0 关闭新增色彩项，原有日月与大气积分继续工作。下界和末地不使用该效果。

## 维度

下界保留游戏提供的生物群系雾色，在低处适量增加暖色层次，并加入缓慢漂移的非均匀烟霭。已有局部 GI 为烟霭提供有限范围的柔和辉光，不产生没有遮挡依据的方向光束。

末地采用冷紫色与青色星云带、独立星点和较弱的冷色半球填充。星点在场景分辨率下计算，星云进入天空缓存，避免低分辨率星点闪烁；背景只依赖世界方向，缓慢动画与相机平移分离。材质和水面反射接入相同维度配色。具体环境控制见[维度说明](dimensions.md)。

## 预算

| 项目 | 默认值 | 调节 |
| --- | --- | --- |
| 地面雾强度 | 0.5 | 0 停止这一层雾 |
| 地面雾高度 | 8 方块 | 控制指数衰减尺度 |
| 氛围积分步数 | 10 | 6 / 10 / 16，复用体积场分辨率 |
| 极光强度 | 0.8 | 0 停止极光积分 |
| 极光速度 | 1 | 0 冻结，1 / 2 / 3 加速 |
| 极光步数 | 12 | 8 / 12 / 16，只影响天空缓存 |
| 晨昏色彩 | 0.7 | 0 关闭新增晨昏项 |
| 下界氛围 | 0.65 | 0 关闭新增烟霭与暖色层次 |
| 末地氛围 | 0.65 | 0 恢复基础虚空环境 |

地形缓存位于现有光照图集的保留行，不增加采样器；雾复用现有体积附件，不增加全分辨率渲染目标。默认半分辨率，低预设为四分之一；低、中、高、极高预设的氛围步数分别为 6 / 10 / 16 / 16，极光步数分别为 8 / 12 / 12 / 16。完整参数见[配置说明](configuration.md)。

空气散射和新增雾按光学深度合并，避免直接叠加两层完整蒙色；透明玻璃使用后方不透明深度约束体积，水面则用单独的界面深度截断。水下保留原有清晰的水体光学路径。

## 依据

- [Epic Exponential Height Fog](https://dev.epicgames.com/documentation/en-us/unreal-engine/exponential-height-fog-in-unreal-engine)：高度衰减、起始距离与不透明度限制的实践。这里另用原生地表缓存适配方块地形。
- [NASA Auroras](https://science.nasa.gov/sun/auroras/)：极光颜色与上层大气发光的背景资料。本项目的幕形、可见范围和亮度为艺术化设计。
- [OptiFine 渲染属性](https://github.com/sp614x/optifine/blob/master/OptiFineDoc/doc/shaders.properties)：维度入口、缓冲与参数接口。
