# 水体改进

本轮移除水上视角的水底视深折射，并重新建立水下观察水面时的界面层。水上水底保持原位置；水下斜视水面时，环境反射增强，水上景物与水下前景具有明显区别。

## 水底采样

颜色与不透明深度始终使用原屏幕坐标，水内光程取水面与几何位置之间的视线距离。删除了折射射线求交、逐层限制、坐标回退与屏幕边缘收敛逻辑。波浪继续作用于水面法线、几何和倒影；聚光仍沿入水阳光方向投影。

`WATER_REFRACTION_STRENGTH` 保留配置标识以兼容已保存的设置，界面名称改为“水下波动强度”。它仅控制水下看向水面的轻微偏移。

## 水下界面

本地 Sildur 的 `composite1.fsh` 在水下仍保留反射材质分支，用水体环境色处理反射回退，并单独计算距离雾。本项目参考这种效果分工，重新实现宽瓣环境反射、深度分类与光程合成；没有移植 Sildur 的代码、固定配色或参数。

水面前后的深度差决定当前像素属于水下前景还是穿过水面的景物。穿过界面时，先对水上图像进行轻度过滤，再按观察角度混合环境反射。斜视时反射占比最高约 0.88，垂直上望时接近原有水体 Fresnel。角度过渡采用宽区间，保留连续可见范围。

环境反射颜色来自本项目的水体散射与水面当地光照。水下物体的清晰镜像不参与这层合成，因此不会出现薄轮廓的屏幕空间命中在帧间跳变。水面仍随波浪法线缓慢变化，并保留最多 1.25 像素的轻微透射波动。水下前景不接受这层反射与过滤。

该处理是面向稳定性与界面辨识的实时近似，不是完整的粗糙介质 BSDF 或全反射模拟。

## 水上反射

默认粗糙度为 0.25，反射强度为 0.3。倒影采用透视正确的屏幕空间 DDA，允许背景进入粗糙滤波轮廓，排除明显更近的前景；部分清晰倒影过渡到当地散射。水的法向反射率保持约 2%。

## 水内光照

聚光由两层低频平滑噪声形成，受日照、遮挡、水深及接收面朝向控制。日照散射采用半分辨率固定八步积分，阴影在实际纹素中心比较后双线性插值。夜间和无天光洞穴跳过日照散射。

| 通道 | 职责 |
|---|---|
| `composite` | 半分辨率云；水下估计一次入水深度 |
| `composite1` | 半分辨率水下光柱与路径元数据 |
| `composite2` | 水体透射、反射、聚光、光柱与云合成 |
| `composite3` | 泛光亮部提取 |
| `composite4` | 泛光过滤 |

本轮未新增纹理附件或渲染通道。水上透射不再执行最多六十四步的折射 DDA；水下环境反射使用当地辐射近似。没有可靠的逐帧 GPU 性能对照，因此不报告 FPS 变化。

## 验证

使用此前保存的真实 GPU 帧，检查阶梯水底、水下上望、跨水面立柱、运动采样、早晨、夜间和洞穴。回归检查要求水下波动开关对水上水底无影响，界面反射对水上区域有可见贡献，且不改变水下前景。

42 个 GLSL 入口、75 个设置与 11 个页面检查通过。实际 GPU 同帧对照中，水下波动开关对水上阶梯水底的平均像素差为 0；水下界面开关在水上景物区域的平均通道差为 27.458915，在水下前景区域为 0.000258。水下前景相对仅保留不透明图像与光程衰减的误差为 0.009961。夜间和洞穴关闭聚光、光柱后的差异均为 0。数值范围为 0～255，仅用于这些固定镜头的回归检查。

前一轮视深折射的记录保留在 `.preview/water-boundary-final/`；本轮以 `.preview/water-interface-v2-final/` 和 `.preview/water-interface-v2-checks/` 为准。

## 使用

同步光影后按 F3+R 重载，无需更换 Mod。“水下波动强度”设为零可关闭界面的采样偏移；水面下侧的环境反射与水内吸收仍然生效。

## 来源

- [Sildur 官方说明与更新记录](https://sildurs-shaders.github.io/changelogs/)及本地 Sildur `shaders/composite1.fsh`：水下反射环境色与距离雾的分工。
- [PBRT 反射与透射](https://www.pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission)：水到空气界面随角度改变反射与透射。当前实现对该角度关系作宽过渡近似。
- Walter、Marschner、Li 与 Torrance（2007），[Microfacet Models for Refraction through Rough Surfaces](https://www.cs.cornell.edu/~srm/publications/EGSR07-btdf.pdf)：粗糙表面的反射与透射分布；本项目没有实现其完整模型。
- [NVIDIA 阴影抗锯齿](https://developer.nvidia.com/gpugems/gpugems/part-ii-lighting-and-shadows/chapter-11-shadow-map-antialiasing)：阴影比较结果的过滤。
- 用户提供的[海面渲染文章](https://bbs.csdn.net/weixin_42571444/article/details/100544715)与[水面及海洋渲染](https://www.plumephp.com/graphics-water-ocean-rendering/)：用于核对颜色、深度、反射与散射的工程分工。
