# 全局光照

GI-01 在当前 Windows 无 Mod 管线上增加局部体素漫反射。原有日月直射、彩色局部光、材质反射及最低环境亮度继续独立计算。

## 原理

阴影阶段从原生地形提交中采集方块占用、线性反照率及天光等级，复用 RGB-MOVE2 的独立 C5 整数图像。普通实心方块原先未使用的发光等级位保存天光；真实发光方块保留原来的颜色、等级与身份。

C12 保存六个方向的间接辐射。日月照到的表面、实际暴露于天空的表面和受到附近光源照明的表面产生第一次漫反射。光通过空气传播，遇到实心方块后，仅在对应的外侧面继续反射，不能直接从亮的一面穿到背面。多弹模式把入射间接光乘以材质颜色与反射率后继续传播。

局部灯光注入复用各光源独立的 RGB 透射缓存。日月注入读取原生阴影深度；天光还需检查该面外侧的向上通路，避免把同一方块外侧的天光用到封闭内侧。透光体对传播进行颜色衰减。

空气传播的方向权重总和不超过一，材质反照率限制为 0.85，后续反射再乘 GI_REFLECTANCE。默认反射率 0.65 用于限制反馈，避免越迭代越亮。接收表面从外侧空气插值采样，排除实心格，减少一格墙两侧的互相污染。

## 选项

入口为“光照 → 全局光照”。

| 选项 | 作用 |
| --- | --- |
| GI计算质量 | 0 关闭；1、2、3 分别每帧执行 1、2、3 次传播。提高后收敛更快，稳态亮度基本相同。 |
| 多次反弹 | 开启后允许间接光继续在表面反射；关闭后仅保留直接照明产生的首次表面反射。 |
| 间接光强度 | 只缩放表面接收的 GI，默认 0.7；0 隐藏 GI，但保留其计算。需要节省计算时将质量设为 0。 |
| 间接光反射比例 | 控制后续反弹的能量保留，默认 0.65。较高数值使暗部与颜色溢出更明显。 |
| 光照体积范围 | 与彩光共享的水平边长，32、48、64、96 格可选，竖直范围为一半。范围增大会增加显存与传播成本。 |

Low、Mid、High、Ultra 默认分别采用 32/48/64/96 格范围及 1/1/2/3 次每帧传播。所有档位默认开启多次反弹。质量与强度可在选定预设后独立调整。

GI 独立于彩光开关。关闭彩光后保留普通方块直射，GI 仍使用共享体素。只有两者都关闭时，采集、光源传播、透射缓存与 GI 计算才全部停止，相关附件缩为 1×1。

## 历史

每个光场保存自己的整数原点和帧号。相机跨格移动时重定位旧格，新增覆盖不读取旧数据；重载、远距离传送和浮动原点跳变会拒绝不对应的历史。覆盖权重跟随连续相机位置，在边界平滑消退。

半浮点附件不能直接保存任意世界整数坐标，原点按三个 10 位分量拆开保存。OptiFine J9 每帧重置纹理翻转索引，因此奇数次传播后补一次复制，确保下一帧仍能读到完成的光场。

## 验证

生成入口仍为 tools.preview.conventional，不能直接安装根目录 shaders。四档、彩光开关、独立 GI 关闭和三维度阶段由完整装配后的编译矩阵检查。tools/check_global_illumination.py 使用生成的正式 GI 着色器，检查首次反射、后续表面反射、封闭室、收敛和远原点一致性。该工具的合成数据只进入独立离屏上下文，不会传给游戏。

原生测试在存档副本中建立天空开口、彩色墙、拐角和封闭对照室，只通过普通方块编辑建场景。截图需等待相机到位和地形提交稳定；不能把着色器重载期间的空场景当成对照。实际 GPU、选项、C12 读回、完整编译结果、帧时间与部署信息保存在 local-docs/migration/checkpoints/GI-01。

## 边界

这是有限范围、一格分辨率的低频 GI。细栅栏、台阶、薄片和复杂透明体仍受原有体素近似限制；不提供精确路径追踪或完整世界的无限距离反射。空气传播采用六方向近似，会比真实光线更柔和；多弹随帧逐步收敛，编辑、快速移动和传送后可能短暂变化。范围外继续使用既有环境光与原版方块照明。
