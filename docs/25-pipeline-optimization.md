# 管线优化

本轮以 0.2.0 为基础，优化泛光、风摆、云影缓存和水体，并增加薄植被逆光透射。修改位于 Shader；配套 Mod 的接口与算法保持兼容。

## 思路

[知乎文章](https://zhuanlan.zhihu.com/p/2094752555377094936)介绍了 Vibrant Visuals 的渲染演进。其原始资料为 A.J. Fairfield 的 [GDC 2026 演讲幻灯片](https://media.gdcvault.com/gdc2026/Slides/Fairfield_AJ_ModernizingTheRenderingOfMinecraft.pdf)。本轮主要采用按效果独立调节分辨率、复用已有光照场、限制薄材质透射范围和按画质预算分配采样的思路。

当前仍使用 OptiFine 的前向几何着色与合成通道。没有引入 RenderDragon 的引擎架构、完整 PBR 资产库或 SWAR 光传播；项目已有按光源颜色分组的后台传播，这一轮优先处理能直接验证的 GPU 重复工作。

## 泛光

原来两道全分辨率过滤，每像素合计读取 26 次。现在拆为三道：

| 通道 | 操作 | 默认视口 |
| --- | --- | --- |
| `composite3` | 四个象限先提取亮部、限制峰值，再平均 | 半宽、半高 |
| `composite4` | 配对高斯权重，7 次线性读取做水平过滤 | 半宽、半高 |
| `composite5` | 7 次线性读取做垂直过滤 | 半宽、半高 |
| `final` | 从有效泛光区域读取并重建到输出 | 窗口尺寸 |

对亮部先提取再平均，可以避免细小火把被降采样后的阈值吞掉。对偶数尺寸，四个输入样本位于原始像素中心；奇数尺寸使用覆盖四个象限的过滤近似。核权重归一化，保持恒定亮部的能量与 RGB 比例。

半径按场景像素定义，选择半分辨率不会把模糊半径直接扩大一倍。相邻权重配对使用硬件线性插值；非整数采样间距下属于高斯近似，不能声称与旧 13 点离散核处处相等。半分辨率会损失部分极细亮部空间细节，全分辨率选项保留更高精度。

缓冲继续分配为全尺寸，前期用于天空和体积场；泛光只写左下有效视口。所有过滤与最终读取均钳制到有效纹素中心，防止把视口外的旧天空、水下散射或清屏颜色卷入画面。太阳可见度只在首个 alpha 纹素中保存，并独立传递，关闭泛光不会连带关闭镜头光晕。

后处理页面新增 `BLOOM_RESOLUTION`：0 半分辨率，1 全分辨率。低、中、高预设使用半分辨率，极高使用全分辨率。默认阈值、强度和半径保持 1.0、0.4、2.0。

## 风摆

此前法线通过四次完整风场查询求切向差分，叠加顶点位移本身，每个植被顶点重复求解五次。

叶片位移仅依赖一个空间相位，现在直接求其解析导数，变换两条切向量后取叉积。草木、庄稼的风场在固定根部上只随高度改变，现在复用当前位移计算高度方向的差分，保留根部、顶端限幅和高度补偿的边界行为。

主视图与阴影的位移函数保持一致，优化只减少法线计算中的重复哈希与三角函数。14 组顶点、两个时刻的 GPU 探针确认位移逐值一致，新旧法线最大角度差约 0.078°；根部、双格接缝和共享叶片顶点误差为 0，主视图与阴影位移误差小于 9×10⁻⁸ 方块。

## 无效计算

- 日月直射或阴影传递为零的表面跳过云影积分；仍保留非零的玻璃透射色，局部光和 GI 独立计算。
- 空气云影缓存存储标量透射率，可用一次硬件线性读取替代四次手动读取。阴影深度仍先逐纹素比较，不能按同样方式直接插值原始深度。
- 相机位置决定的低频空气密度在全屏顶点阶段求值，减少每个体积片元对相同两个噪声纹素的读取。
- 水底焦散先检查有效日照、深度、朝向、像素足迹与入射遮挡，再生成两层胞元纹理。足迹导数在提前退出前计算，避免新增分支破坏相邻片元导数。
- 水面 GGX 跳过背向波面和辐射为零的日月光源。SSR 遇到天空深度时不再重建无用的视图位置，粗糙反射滤波也直接接受天空背景。

这些变化减少具体路径上的工作量。只有泛光做了独立 GPU 计时；不能据此为其它单项或整帧分配未经测量的提速百分比。

## 植被透光

`FOLIAGE_TRANSLUCENCY` 控制树叶、草木和庄稼的日月逆光透射，默认 0.4，0 关闭。日月阴影图给薄植被写入独立类别标记；普通接收面仍把这些叶片作为不透明遮挡处理。

透射只在背光面生效，并检查最近投影体属于薄植被。沿光线估计的厚度增加时快速衰减，约 1.5 格后完全截止；最近遮挡若是实体墙则不补光。四个阴影样本软化类别边缘，效果还受当地天光、云影、日月亮度、材质颜色与表面朝向限制。

这是单层、风格化的薄材质近似。它不改变方块 alpha，不追踪多层叶片内部散射，也不宣称严格还原叶肉光谱或完整能量守恒。阴影范围外没有透射补光，远处通过阴影距离淡出。

## 质量预算

新增 `AIR_SCATTER_STEPS` 和 `WATER_SHAFT_STEPS`。日光散射使用固定的二次距离区间，每区间仍有两次过滤阴影查询；调整步数不会引入随时间变化的随机采样。水下光柱维持固定中点积分。

| 预设 | 日光区间 | 水下光柱步数 | 泛光 |
| --- | --- | --- | --- |
| 低 | 16 | 4 | 半分辨率 |
| 中 | 32 | 8 | 半分辨率 |
| 高 | 32 | 12 | 半分辨率 |
| 极高 | 48 | 16 | 全分辨率 |

默认日光和水下步数保持 32、8。低档减少阴影查询，高档增加光路采样；细光束的稳定性与开销需要按场景权衡。完整参数见[配置说明](configuration.md)。

## 测量

Apple M3、macOS、OpenGL 4.1，1920×1080 HDR 输入。使用仓库实际泛光函数、RGBA16F 中间附件和线性过滤，预热 5 次后记录 25 次 GPU 查询的中位数。计时包含泛光和最后一次全屏重建，不含游戏几何、云、水体或 Mod 求解。

| 方案 | 两轮中位数范围 |
| --- | --- |
| 旧全分辨率两道过滤 | 1.87～2.72 ms |
| 新默认半分辨率 | 0.74～0.92 ms |
| 新全分辨率 | 1.65～1.90 ms |

两轮中默认方案约节省 51%～73% 的独立泛光时间。分轮测试仍受 GPU 时钟、调度和功耗状态影响，这些数值不能换算成游戏 FPS，也不能保证其它显卡获得同样比例。

## 检查

`tools/check_bloom.py` 使用实际 GLSL 验证恒定场能量、纯黑场、1×1 与奇数视口、有效区外的高亮哨兵残留、小光源四种像素相位、RGB 比例和关闭效果。

```bash
python3 tools/check_glsl.py
python3 tools/configuration.py --check
python3 tools/check_bloom.py --baseline-shaders .preview/optimization/baseline/shaders
```

真实客户端分阶段采集了 18 个画面，均与各自的 GPU 重放一致。最终扩展检查覆盖逆光、顺光、夜间植被、风摆阴影、昼夜水底焦散和水下光柱七个默认设置镜头，另以关闭配套 Mod 求解的隔离变体验证了两幅林地昼夜画面。

| 同帧对照 | 结果 |
| --- | --- |
| 只关闭植被透光，无实体遮挡薄叶区域 | 平均显示通道差 0.866 |
| 只关闭植被透光，实体墙前薄叶区域 | 差异为 0 |
| 恢复旧水体工作调度，昼夜焦散和水下光柱 | 逐像素一致 |
| 恢复旧空气缓存与密度求值，林地斜射日光 | 平均显示通道差 0.00112，最大单通道差 1/255 |
| 同上，夜间林地 | 逐像素一致 |
| 日光散射从 32 步降为 16 步，斜射林地 | 平均显示通道差 0.222，最大单通道差 10/255 |

显示通道差按 0～255 计，不是线性 HDR 辐射差。较低步数的结果允许有质量损失，不代表与默认图像相等。默认设置的七镜头回归可运行：

```bash
python3 tools/check_optimization_scenes.py --reference-shaders .preview/optimization/baseline/shaders
```

采集器现在只为隔离实例关闭 Forge 的早期窗口，避免本机 CGL 捕获时的窗口交接竞争；林地就绪条件检查实际石墙和树干是否到达客户端，不再依赖随视距、分辨率变化的固定区段数。泛光分辨率属于加载器视口配置，离线预览在该选项改变时会要求重新采集。

基线目录为本轮保留的旧 Shader 副本；其它机器可以从 0.2.0 标签提取到独立目录。GPU 探针与报告位于 `.preview/bloom-verification/`、`.preview/optimization/wind-probe/`，本地捕获与存档副本不纳入 Git。

后续迭代的体积分辨率、天空周期边界和未采用方案见[体积缓存](26-volume-cache.md)。
