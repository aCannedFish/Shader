# 画面修复

2026-10-29 SKY-01：用户天空竖直黑线定位为经度环绕浮点mod越界；1960×1104对应245列，mod(width,width)可能得到width并读取相邻黑色缓存。改为显式边界环绕。三种尺寸/过滤独立GPU检查、RTX4060同位置同分辨率晴雨及偏转镜头对照通过，已备份部署；其余水体目标保持进行中。

2026-10-27，针对水下黑天、多光源抖动、场景偏暗、雨天蓝色倒影和远云堆积进行修正。当前生产入口仍为 `tools.preview.conventional`，保留四档与独立彩色开关。原始日志、截图与部署记录保存到 `local-docs/migration/checkpoints/VIS-02`。

## 水下

反射背景有意将天空留黑，水下出射原先直接读取了该背景。现在按每个采样位置的实际不透明深度恢复天空和云，再插值与合成透明层。真实几何继续遮挡天空；无限远深度只用于分类，方向通过有限深度重建，避免无穷投影产生非法值。

## 彩光

原来的顶点写入没有处理同一体素的并发竞争，且占用场复用了后续阶段的屏幕附件。现在使用独立的 R32UI 阴影附件，原子最大值明确材质优先级，发光等级和 RGB 随材质一起保存。灯具颜色不再由周围光场反向写回。

每个体素传播三个光源身份，按照各光源自己的亮度和距离确定候选。历史同时保存原点与帧号，移动时重定位身份，放置、移除、传送和重载时拒绝失效数据。表面在切平面内混合四个邻域的候选，减轻离散候选变化导致的颜色跳变。

每帧在 prepare4 为各候选计算独立体素遮挡和 RGB 透射，结果写入 colortex11 的三个切片。表面叠加各灯颜色和透射，避免每个像素重新遍历体素。colortex8 保存低能量漫反射场，colortex10 以完整浮点保存光源身份和整数世界原点。关闭彩光时跳过采集与传播，并将专用场缓冲缩为 1×1。

遮挡精度受一格体素限制，边缘采用邻域插值。台阶、细杆和透明贴图的局部阴影仍是近似；密集区域每格保留三个主要候选，邻域交界可混合更多灯。局部间接光为 RGB 漫射近似，天空光仍依赖原版天光和环境遮蔽。

## 色调

日间环境光先把天空色归一到单位亮度，再作为色温参与照明，消除染色额外压暗场景的问题。阴雨环境光降低饱和度，夜间采用较温和的冷色。曝光默认 1.0，饱和度 1.0，泛光 0.25，暗角 0.1。

显示曲线小幅提高中间调，保留黑点与高光压缩。低饱和物体的暗部轻微偏冷，亮部轻微偏暖；中性灰和高饱和彩光避免附加染色。饱和度与对比度之后按亮度压缩超出显示色域的色度，减少单通道截断引起的偏色。

## 雨景

隐藏面反射的天空回退采用同一降雨响应，常规反射源中的距离雾也同步天空雾色。水体吸收保留原来的深蓝基调，倒影中的天空和地物随实际天气变化。

## 远云

通过加载器的 far 平面调整云场范围，保留至少若干完整云团，并由 CLOUD_DISTANCE 限制最大距离。模拟距离不代表可见范围，不参与云层选择。

视线先与云层高度范围及有限水平圆柱相交，再进行密度采样。云场外侧同时减弱密度和大气对比度，边界外不采样。云层原有区域高度和厚度变化继续保留，天空、反射和云影共享同一距离规则。

## 验证

数值检查覆盖原子提交顺序、三灯独立遮挡、玻璃 RGB 透射、移除、原点移动、远距离整数精度、帧号回绕及候选切换。色调检查覆盖灰阶单调性、中性灰、光源色相、显示色域、天气连续性与封闭洞穴。云检查覆盖擦边视线、云内外、反射偏移原点及距离淡出。

这些数值检查使用独立 OpenGL 上下文，不能替代游戏画面或帧率。原生检查必须单独记录实际 renderer、分辨率、视距、预设、开关和近似边界；失败运行与通过运行分别保留。
