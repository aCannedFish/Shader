# 配置

本文参数表由 `shaders/settings.glsl`、`shaders.properties` 和语言文件生成，覆盖当前版本全部界面选项。默认值指未覆盖的光影源码值。游戏中已保存的用户设置可能不同；使用光影设置的重置功能可恢复默认值。

## 使用

在“光影设置”调整参数。0/1 开关分别表示关闭/开启；数值参数只能选择表中列出的值。日月阴影与局部阴影分别控制；带“需要配套 Mod”的选项仅在 Mod 有效时生效。

调整活动光源数量、局部阴影分辨率或 GI 体积会重建 GPU 资源。调整反弹次数、传播步数、光源强度或场景更新间隔后，等待下一轮采集和求解收敛。阴影和 GI 在活动范围边缘平滑回退到原版光照。

## 阴影

| 参数 | 标识 | 默认值 | 可选值 | 作用 |
| --- | --- | --- | --- | --- |
| 启用阴影 | `ENABLE_SHADOWS` | `1` | 0, 1 | 日月阴影总开关；0 关闭采样，1 开启。 |
| 阴影柔和度 | `SHADOW_SOFTNESS` | `1` | 0, 1, 2 | 方向光阴影质量：0 单点，1 为 5 点遮挡搜索和 8 点过滤，2 为 9 点搜索和 12 点过滤；半影随遮挡距离增大，无遮挡时提前结束。 |
| 阴影分辨率 | `shadowMapResolution` | `2048` | 1024, 2048, 3072, 4096 | 日月阴影贴图边长（像素）；越大边缘越清晰，阴影阶段带宽与显存随平方增长。 |
| 阴影距离 | `shadowDistance` | `96.0` | 64.0, 96.0, 128.0, 160.0 | 日月阴影覆盖距离（方块）；越大远处阴影越多，同分辨率下越糊，阴影阶段几何量随之增加。 |
| 阴影畸变 | `SHADOW_MAP_BIAS` | `0.95` | 0.0, 0.5, 0.75, 0.9, 0.95 | 日月阴影纹素向近景集中的畸变强度；不要设置为 1。 |
| 阴影偏移 | `SHADOW_BIAS` | `0.00035` | 0.0001, 0.0002, 0.00035, 0.0005, 0.001 | 深度比较偏移；增大可缓解条纹，过大可能造成阴影脱离物体。 |

## 常用调节

| 目标 | 调整方式 |
| --- | --- |
| 森林与山坡薄雾 | 在“世界 → 氛围”调整地面雾强度和高度，需要当前配套 Mod；0 关闭，水下不受影响 |
| 夜间极光 | 调整极光强度、速度与步数；晴夜向北较明显，速度 0 冻结，强度 0 关闭 |
| 晨昏色调 | 调整晨昏色彩强度；下界烟霭与末地星云由各自的氛围参数控制 |
| 矿物自发光 | 在“材质”调整矿物发光强度；只作用于矿物遮罩，需要当前配套 Mod，0 关闭 |
| 方块倒影 | 在“材质”页面调整反射强度和步数；关闭材质反射可恢复旧表面着色，水面单独控制 |
| 下界或末地过暗 | 在“世界 → 维度”调整各自环境亮度；日月参数与夜间曝光不影响这两个维度 |
| 干净水面 | 关闭水面纹理，保留波浪；散射不透明度默认 0.12，水底只在浅水处较清晰 |
| 调整水底可见度 | 增大散射不透明度，使水上观察时的深水更快被水色遮蔽；减小可恢复清澈水面，水下相机能见度独立控制 |
| 降低塑料感 | 降低水面反射强度和日月高光；不以大幅增加不透明度替代吸收 |
| 增加水的浑浊度 | 增大 `WATER_TURBIDITY`，同时检查深水最低能见度和水下密度 |
| 提升水下可读性 | 保留最低能见度，适量降低水下密度或吸收；当前版本没有水下模糊开关 |
| 让暗处更清楚 | 调整基础环境亮度为洞穴保留可见度；室外夜景再调夜间环境亮度、夜间曝光和月光 |
| 植被逆光透亮 | 调整“植被透光”；0 关闭，效果受日月、阴影材质和厚度控制 |
| 调整云形态 | 使用云覆盖、云团尺度、基准高度与厚度；高度不是所有云底的统一水平面 |
| 雨后地面积水 | 在“世界 → 雨天”调节积水强度；湿度会滞后雨量，屋檐和植被不会整体变成镜面 |
| 山林雨雾 | 在“世界 → 雨天”调节雨雾强度，需要配套地表缓存，与普通地面雾独立 |
| 减少局部光更新延迟 | 增大阴影更新数或 GI 工作预算，必要时降低反弹次数、体积和活动光源数 |
| 缩短阴影范围外的突变 | 保持合理活动体积和半径；无限数量与无限距离的独立阴影不在当前求解范围内 |

## 性能

主页面的“预设”提供低、中、高、极高四档完整组合（见文末“画质预设”）；下表用于在预设基础上单独微调，不代表已在每种硬件上测得固定帧率。

| 参数 | 低开销起点 | 默认 | 高质量尝试 |
| --- | --- | --- | --- |
| 体积场分辨率 | 四分之一 | 二分之一 | 已为最高档 |
| 氛围积分步数 | 6 | 10 | 16 |
| 极光步数 | 8 | 12 | 16 |
| 泛光分辨率 | 半分辨率 | 半分辨率 | 全分辨率 |
| 日光散射步数 | 16 | 32 | 48 |
| 水下光柱步数 | 4 | 8 | 16 |
| 云质量 | 0 | 2 | 已为最高档 |
| 倒影步数 | 16 | 32 | 64 |
| 活动光源数 | 8 或 16 | 32 | 64 |
| 局部阴影分辨率 | 64 | 128 | 192 或 256 |
| GI 体积边长 | 16 或 24 | 32 | 40 或 48 |
| GI 反弹次数 | 1 或 2 | 4 | 4 或 6 |
| 每次反弹传播步数 | 4 | 8 | 12 或 16 |

体积场分辨率缩放云、日光散射、地面雾、维度烟霭和水下光柱；四分之一宽高对应默认体积片元数的约 1/4，细节会变粗。场景纹理、几何和水上景物折射不随该选项降采样。

阴影图存储大致随光源数和分辨率平方增长，体素 GI 的内存和主要工作量随体积边长立方增长。较高每帧预算会减少收敛等待，但增加当前帧工作量。先降低体积、光源数与采样质量，再判断是否需要修改更新预算。
