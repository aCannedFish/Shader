# 真实天空

更新日期：2026-10-10。

## 选型

采用动态天空查找表与半分辨率体积云。大气部分使用球形地球、Rayleigh 散射、Mie 散射与臭氧吸收，并以低成本各向同性项近似较高阶散射。借鉴 Hillaire 2020 的天空视角查找表思路，未完整移植其多次散射查找表或视锥体积模块。云密度与光照借鉴 Nubis 的天气覆盖、分层形状、Worley 侵蚀、Beer 衰减和少量光照步进。

| 方案 | 特点 | 选择 |
| --- | --- | --- |
| Bruneton 预计算大气 | 高维查找表能处理多次散射与不同观察高度，需要较复杂的预计算和额外纹理绑定 | 未移植 |
| 动态天空视角表 | 将昂贵积分限制在小表，适合日夜和气溶胶变化，普通片元通道即可实现 | 采用简化实现 |
| Nubis 风格分层体积云 | 天气场与混合噪声控制形状，可限制采样次数并降低绘制分辨率 | 采用简化实现 |
| 最新完整体素云 | 支持更复杂的云类型与飞行玩法，需要体积数据、加速结构与更多工程设施 | 未移植 |

当前 OpenGL 4.1 和 OptiFine 管线无需计算着色器。云与天空临时复用两张泛光缓冲，颜色缓冲数量维持八张。

## 大气

光学计算以千米为单位。地球半径为 6371，外层大气半径为 6451；Rayleigh 和气溶胶的密度高度尺度分别为 8 和 1.2，臭氧分布位于约 10–40 的高度范围。相机高度按 Minecraft 的方块米数换算并限制到适合地面观察的范围。

每帧在屏幕宽高各 1/8 的区域生成天空视角表。仰角在地平线附近分配更多采样位置，默认每条视线积分 24 段，每段用 6 个非均匀样本估计朝光源的透过率。太阳落到地平线以下时仍可照亮高空大气，形成连续的暮光。

日月方向来自游戏提供的天体位置。地面日光颜色也使用同一大气消光系数的快速空气质量近似，减少天空和地面光色的差异。

## 日月

原版天空、星星和方形日月不再向场景输出颜色。太阳由圆盘、边缘暗化和大气散射光晕构成；月球为球面法线上的月面颜色与日照明暗，游戏的八个月相决定终止线位置，并保留较弱的地球照。

月面纹理来自 NASA SVS 的 LRO/LROC 数据，详情和公共领域使用说明见 `shaders/textures/SOURCES.md`。默认大小倍率为 1.0，按原版贴图的可见亮主体宽度标定：太阳约 8.6 度、满月约 5.7 度。太阳和月球保持圆形轮廓与月面细节，在普通游戏视场下更醒目。较大天体逐像素经过地平线裁剪，月球的暗面同样遮挡背景星点。

星空使用球面分布的程序化星点，使用视线方向的角度导数过滤。月相沿用 Minecraft 的位置和时间系统，没有引入完整的真实天文轨道或历表。

## 云体

云层基准底部高度为 256 方块。区域与云团两个尺度的平滑天气场共同控制高度偏移，默认偏移上限约为 ±125 方块；各处厚度在约 144–240 方块之间变化。因此云底与云顶都有高低层次，高度分布随云团一起移动。视线与云影使用包含所有局部云体的统一外包范围，避免高处云团被固定高度截断。天气场控制覆盖率和垂直形状，周期性混合噪声构成云团，三个 Worley 频段侵蚀边界。云密度连续，不存在原版云块的方形格子。云随风平移，采样图案不随帧号随机跳变。

主视线按靠近相机更密集的分布步进，空区域跳过光照计算，透过率低于 0.015 时终止。每个非空样本计算少量朝光源的密度样本，并用近似多次散射和粉末项补充云内部照明。远处云逐渐融入同一大气背景，太阳、月亮和星星由实际云体光程遮挡。

云按半分辨率绘制，随后通过深度约束重建到全分辨率，防止云色越过前景轮廓。云内外镜头共用同一密度场；相机进入云层时，眼前的光程从相机开始积分。未使用时域累积，因此移动时没有历史帧拖影，较低质量下仍可能出现空间采样噪点。

## 衔接

远景继续使用已有的加载距离雾衰减，只把其颜色贡献替换为当前方向的大气颜色。透明绘制前的场景副本同步修正，水面倒影和水下看水上使用相同天空和体积云。

水面离屏反射采用 16 个云视线样本和 2 个光照样本。日月直射高光仍由原有 GGX 模型处理，反射环境不重复累加天体圆盘；水下透射天空则保留天体圆盘。

地面日月直射使用五个粗密度样本近似云影，云影不乘到局部光或天空散射上。该做法提供柔和的云团遮挡，不包含完整体积光柱或严格的地面多次散射。

## 通道

| 阶段 | 写入 | 任务 |
| --- | --- | --- |
| deferred | colortex3 的 1/8 区域 | 天空视角表 |
| deferred1 | colortex6 | 修正天空与雾的不透明 HDR 副本 |
| composite | colortex4 的 1/2 区域 | 体积云辐射与不透明度 |
| composite1 | colortex0 | 天空、水体与云重建合成 |
| composite2 | colortex3 | 合成之后的泛光提取 |
| composite3 | colortex4 | 泛光模糊 |
| final | 屏幕 | 色调映射与显示编码 |

同一缓冲区的复用发生在不再需要上一用途之后，读写不在同一阶段冲突。

## 设置

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| SKY_HAZE | 1.0 | 气溶胶浓度与太阳附近散射 |
| SKY_EXPOSURE | 1.0 | 天空辐射倍率 |
| SKY_SAMPLES | 24 | 小表中的积分精度 |
| CELESTIAL_SIZE | 1.0 | 相对原版可见主体大小的倍率 |
| CLOUD_QUALITY | 1 | 低、均衡、高质量 |
| CLOUD_COVERAGE | 0.50 | 天气场覆盖率 |
| CLOUD_DENSITY | 1.0 | 云体光学密度 |
| CLOUD_BRIGHTNESS | 1.0 | 云散射亮度 |
| CLOUD_HEIGHT | 256 | 云层基准底部高度 |
| CLOUD_THICKNESS | 192 | 云层基准厚度，同时决定高度起伏幅度 |
| CLOUD_SIZE | 640 | 噪声体的主要形状尺度 |
| CLOUD_SPEED | 4.0 | 风速，单位约为方块/秒 |
| CLOUD_SHADOW_STRENGTH | 0.65 | 日月直射的云影强度 |

低、均衡、高质量分别使用 24/2、40/3、64/5 个视线/光照样本。新增选项位于世界页面的真实天空和体积云子页面。

## 预览

纹理生成命令：

```bash
.preview/venv/bin/python tools/build_sky_assets.py
```

噪声和 NASA 月面合并为一张 1024×1024 图集。每个三维噪声切片保留包裹边缘，以普通二维纹理实现连续三维采样。纹理与 `.mcmeta` 加入捕获配置校验，修改它们需要重新捕获；日常密度函数和光照参数迭代仍可离线重放。

太阳、日出、日落、满月、弦月、新月与云层内外镜头加入固定场景。当前场景数为 53，着色器入口为 40。
