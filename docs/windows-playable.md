# 运行版

本分支面向 Windows、Minecraft 1.21.11 和 OptiFine J9，使用 OpenGL 4.5。光影本身不需要配套光照 Mod。目标机为 Core Ultra 7 155H、32GB DDR5、RTX 4060 Laptop；Windows 原生检查与旧版 macOS 记录分别保存。

## 安装

使用检查点提供的光影包，或从源码生成完整目录。在游戏光影页面选择 SimpleShader，然后进入光影设置。已保存的旧选项可能覆盖新默认值；检查点部署会保留旧选项备份，并使用新的 Low 默认配置。

实际游戏目录为 `F:/Minecraft/.minecraft`，启动器为 `D:/Apps/HMCL-3.17.0.361.exe`。同步的光影目录是 `shaderpacks/SimpleShader/shaders`。每个可部署检查点先备份旧包和选项，再核对安装文件的 SHA-256。

## 预设

主页面提供 Low、Mid、High、Ultra 和独立的彩色光照开关。切换预设调整采样与范围，彩色光照开关单独保存。默认选择 Low，关闭彩色光照。

| 预设 | 阴影尺寸/距离 | 体积比例 | 材质SSR步数 | 水面SSR步数 | 彩色范围/更新 |
| --- | --- | --- | --- | --- | --- |
| Low | 1024 / 64 | 1/4 | 16 | 16 | 32 / 1 |
| Mid | 2048 / 96 | 1/2 | 24 | 32 | 48 / 2 |
| High | 3072 / 128 | 1/2 | 32 | 64 | 64 / 3 |
| Ultra | 4096 / 160 | 1/2 | 48 | 64 | 96 / 4 |

体积比例是宽、高各自的比例。彩色范围是相机周围的水平边长，竖直边长为一半，单位为方块；更新次数越高，移动和编辑后收敛越快。Low 使用硬阴影，Mid 和更高档位增加软阴影过滤；Ultra 还提高泛光与水下采样预算。

优先从 Low、关闭彩色光照开始，根据帧率提升档位。低性能设备可配合 OptiFine 的渲染比例选项；高档位适合有更多 GPU 预算的设备。本机性能记录使用 1920×1080、内部比例 1.0、视距 12，不能把分辨率不同的结果直接横向比较。

## 光照

关闭彩色时保留普通方块光、环境光、AO 和日月阴影，跳过彩色体素采集与传播。开启后，附近常见可绘制光源的色调通过紧凑体积传播；覆盖范围外和未采集的光源使用普通方块光。

局部遮挡与间接光采用原版光照场、AO 和可选 RGB 传播近似。它们替代旧版逐灯六面阴影和多跳方向场，精度与旧路径不同。日月阴影、材质反射、体积云、水与水下光学、天气、植被和显示处理继续保留。

## 反射

材质、水和积水使用有步数上限的屏幕反射，结合环境与阴影信息回退。屏幕深度没有记录的背面和屏外物体使用近似。接收面裁剪排除自身命中，离屏射线停止采样；材质 ID 先取整，避免插值误差把金属像素归为普通材质。

矿物发光按纹理颜色区分矿物与宿主，煤不发光。该实现适合原版及保留相近配色的资源包；特殊配色可调整矿物发光强度。它不依赖运行时矿物遮罩上传。

## 构建

在源码工作目录执行：

```powershell
python -X utf8 -m tools.preview.conventional --target .build/SimpleShader/shaders --preset LOW
```

将生成目录的 `shaders` 文件夹放在光影包根目录。目标目录必须是新目录，避免混入旧构建。`--colored`可改变初始开关，四档与开关仍可在游戏中调整。仓库根 `shaders/` 是共享艺术源码，需经构建器装配。

## 证据

2026-10-27 的 VIS-02 修正水下天空、多灯稳定性、色调、雨天倒影和远云。Low 开彩光以同样的 1080p、比例 1.0、视距 12、预热 30 秒和采样 45 秒测得静止 76.565 FPS、走动 64.135 FPS，P95 为 17.909 和 22.115 毫秒。旧版下面的数据保留作历史记录，不能代表本次修复版。相邻灯、逐灯遮挡、数值检查和范围限制见 [画面修复](visual-repairs.md)。

最终 Low 包在目标 RTX 4060 Laptop 上，以1080p、内部比例1.0、视距12、固定镜头，预热30秒后采样45秒：彩色关闭82.078FPS，开启73.527FPS；帧间隔P95分别15.999和17.824毫秒。近距多灯移动场景的早期同管线记录为95.825FPS、P95为14.733毫秒。不同场景有不同开销，四档预算与全部原始条件在重构记录中列明。

实现选择、同场景对照、失败定位与本机性能见 [重构记录](migration/redesign.md)。原始 Windows 日志、截图、GPU 时间戳和配置保存于 `local-docs/migration/runs`，部署记录保存于对应检查点。测试助手只用于隔离实例，发布的光影包不包含测试 Mod。

2026-10-28 GI-01 已加入可调的局部体素多弹GI，并备份同步实际实例；Low彩光+GI在1080p/视距12下静止81.777FPS、移动68.508FPS，High连续输入及三维度通过。选项和有限体积边界见 [全局光照](global-illumination.md)。
